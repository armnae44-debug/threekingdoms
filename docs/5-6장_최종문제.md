# 5·6장 최종 문제 목록

- 범위: 5장(백마, A·B 두 갈래), 6장(연진, A·B 두 갈래). 모든 줄을 조건과 함께 다시 읽었습니다.
- 줄 번호는 화면 대본(`5장A` = 데이터 6A, `5장B` = 6B, `6장A` = 7A, `6장B` = 7B)의 `#번호`입니다.
- **결과: 확실한 문제는 10건입니다.** 100건을 채우려고 억지로 늘리지 않았습니다. 5·6장은 이전 검수에서 이미 많이 고쳐져서, 남은 것은 아래가 전부입니다.
- 고침 문장은 모두 앞뒤 줄, 높임말, 조건과 맞춰 봤습니다.

| 분류 | 건수 | 번호 |
|---|---|---|
| A. 앞뒤가 맞지 않음 (모순·순서) | 6 | 1, 2, 3, 4, 5, 6 |
| B. 장면 묘사가 다른 줄과 어긋남 | 2 | 7, 8 |
| C. 문장 (시제·반복) | 2 | 9, 10 |

## A. 앞뒤가 맞지 않음

### 1. 5장 우물가 `장료에게 맡긴다`: 장료의 말이 저녁 곤장 뒤에 나옴 (A·B 둘 다)

조건: `well=refer`

| | 줄 |
|---|---|
| 5장A #139 / 5장B #120 | 나: "양쪽 다 장료 장군께 데려가겠소. 판단은 장군께서 하실 거요." |
| 5장A #141 / 5장B #122 | 장료는 이야기를 끝까지 듣고 장수에게 사람을 보냈다. **그날 저녁**, 장수 군에서는 먼저 입을 연 병사가, 우리 쪽에서는 왕삼이 곤장 다섯 대씩 받았다. … |
| 5장A #143 / 5장B #124 | 장료: "장수 쪽 처분은 **내가 따로 말하겠소**. 그대는 돌아가 병사들부터 단속하시오." |

문제: 저녁에 장수 군 병사까지 곤장을 맞았다고 이미 말한 뒤에, 장료가 "장수 쪽 처분은 따로 말하겠다"며 나를 돌려보냅니다. 시간이 거꾸로 갑니다.

고침: 장료의 말을 서술 안으로 넣어 순서를 바로잡고, 따로 있던 장료 대사 줄은 숨깁니다. 같은 줄 뒤쪽에 "제 병사 단속을 못 했다고"가 있어서, 겹치지 않게 "단속" 대신 "다잡으라고"를 씁니다. (`왕삼 생존`이 아닐 때 나오는 "그 고참" 줄도 같은 방식으로 고칩니다.)

| | 지금 | 고친 뒤 |
|---|---|---|
| #141 / #122 | 장료는 이야기를 끝까지 듣고 장수에게 사람을 보냈다. 그날 저녁, … | 장료는 이야기를 끝까지 듣고 장수에게 사람을 보냈다. **내게는 돌아가 병사들부터 다잡으라고 했다.** 그날 저녁, … (뒤는 그대로) |
| #142 / #123 | (같은 문장, "그 고참" 판) | (같은 방식) |
| #143 / #124 | 장료: "장수 쪽 처분은 내가 따로 말하겠소. …" | 숨김 |

### 2. 5장B 우물가 `장료에게 맡긴다`: 군막을 나서자마자 "곤장을 맞았다"고 답함

조건: `well=refer`

| | 줄 |
|---|---|
| 5장B #122 | … **그날 저녁** … 곤장 다섯 대씩 받았다. |
| 5장B #134 | **장료의 군막을 나서는데**, 여포가 말을 끌고 지나가다 멈췄다. |
| 5장B #138 | 여포: "아까 우물가 일로 장료한테 갔다며. 어찌 됐냐." |
| 5장B #139 | 나: "양쪽 다 다섯 대씩 **맞았습니다**." |

문제: 장료 군막을 나서는 때는 오후입니다. 곤장은 저녁에 쳤으니, 그때는 아직 맞기 전입니다.

고침: 여포를 만나는 때를 곤장 뒤로 옮깁니다. 바로 앞 #122가 "그날 저녁"으로 시작하므로 같은 말을 되풀이하지 않습니다. #138의 "아까 우물가 일로"와도 맞습니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #134 | 장료의 군막을 나서는데, 여포가 말을 끌고 지나가다 멈췄다. | 곤장이 끝난 뒤, 여포가 말을 끌고 지나가다 내 앞에서 멈췄다. |

### 3. 5장A 관우와의 곳간 이야기: 대답한 뒤에 "대답하지 못했다"

조건: `a6_granary=store` + 3장에서 은을 받은 경우(`ch3=bribe`). 은을 받으면 `accomplice`도 함께 켜집니다(코드 3343줄).

| | 줄 | 조건 |
|---|---|---|
| #383 | 관우: "그 은으로 그대 병사들은 배불렀소?" | ch3=bribe |
| #384 | 나: "…아닙니다. 배급은 그대로였습니다." | ch3=bribe |
| #385 | **나는 대답하지 못했다.** | accomplice (bribe도 포함됨) |

문제: 방금 "아닙니다"라고 대답했는데 바로 "대답하지 못했다"가 나옵니다. #385는 원래 거래(`deal`) 갈래의 #382 "다른 부대를 굶겼다는 말이오?" 뒤에 붙으려던 줄입니다. 같은 묶음의 #371·#380~382는 이미 `!flag:ch3=bribe`로 막혀 있는데 #385만 빠졌습니다.

고침: #385 조건에 `!flag:ch3=bribe`를 더합니다. 문장은 그대로 둡니다.

### 4. 5장B 관우와 여포: 관우가 아무 말도 안 했는데 "여포는 대꾸하지 않았다"

| | 줄 |
|---|---|
| #407 | 여포: "이런 것 말고. 내가 싸울 때마다 남에게 빌리지 않아도 되는 군사." |
| #412 | 관우가 고개를 끄덕였다. |
| (#413 숨김) | ~~관우: "나는 형님께 돌아갈 일을 하고 있소. 온후는 군사를 되찾을 일을 하시는 것이고."~~ |
| #414 | **여포는 대꾸하지 않았다.** |
| #415 | 잠시 뒤 그가 비단을 집어 들었다. … |

문제: 예전 검수에서 관우의 말(#413)을 숨기면서 #414만 남았습니다. 관우는 고개만 끄덕였으니 "대꾸"할 말이 없습니다.

고침: #415의 "그"가 여포를 가리키도록, 여포를 주어로 둔 채 문장만 바꿉니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #414 | 여포는 대꾸하지 않았다. | 여포는 관우 쪽을 보지 않았다. |

읽히는 순서: 관우가 고개를 끄덕였다. → 여포는 관우 쪽을 보지 않았다. → 잠시 뒤 그가 비단을 집어 들었다.

### 6. 6장B 문추 장면 `여포 뒤로 붙는다`: 여포가 안장 옆으로 기운 적이 없는데 모닥불에서 그 이야기를 함
