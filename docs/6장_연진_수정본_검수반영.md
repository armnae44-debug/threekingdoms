# 6장 연진 수정본

`6장_검수.md`의 1~3차 내용을 모두 반영한 뒤 게임에서 그대로 뽑은 대본이다.

- 장면 제목의 "제N장"은 게임 원고 번호다(화면 장 번호보다 하나 크다).
- 같은 자리에 조건이 다른 줄이 여러 개 있으면, 그 판에 맞는 줄 하나만 나온다.

- 읽는 법: **이름**: 대사. 이름 없는 줄은 서술이다. `〔조건: …〕`은 그 판에서만 나오는 줄이다.
- 선택지는 `▸ 선택지 이름 — 설명 (값)`으로 적었다. 줄 앞의 `#번호`는 수정 요청 때 위치를 짚는 번호다.
