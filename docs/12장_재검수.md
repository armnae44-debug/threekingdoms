# 12장 재검수 (관도 · 완결 · 후일담)

- **기준 원고:** 게임에 들어 있는 12장 전부 (`검수_12장_관도.md`).
  - A선 706줄(14A, 후일담 포함)
  - B선 651줄(14B, 후일담 포함)
- **방법:** 검수 방법 §9를 따랐다.
  1. 시간표, 동선 표, 이름(누가 언제 누구를 아는가) 표를 먼저 만들었다.
  2. 대사를 두 줄씩 붙여 읽어 질문과 대답이 맞는지 봤다.
  3. 조건이 갈리는 줄은 갈래마다 따로 따라가며 빈 줄과 겹친 줄을 찾았다.
  4. 앞 장의 원문과 대조했다. 대조한 곳은 아래와 같다.
     - 7장 A: 왕삼이 손가락으로 짚으며 명부를 읽음
     - 8장 A·B: `a9_rescue`, `b9_rescue`
     - 9장 B: `b11_iseok` → `iseokGate`
     - 10장 A: 저수가 교대병 일을 아는 경로(12A #111·#112). 10장 판정 Ⅰ-21로 글자와 출처가 바뀐다(L-4·L-5).
     - 10장 A: 모팔의 물과 조노의 새 창(12A #73·#76)
     - 11장 A: `terms`, `combat`, 조노의 "십 년"(13A #316)
     - 11장 B: 조공의 "공은 관도가 끝나면 갚겠네"(13B #35·#480)
  5. 엔진도 확인했다.
     - **죽은 사람 이름:** 조건이 없는 줄의 조노·왕삼·소칠·모팔은 abText가 노병·방패병 고참 등으로 바꾼다. 문제 없다.
     - **`!조노 생존&소칠 생존`:** `!`가 `&` 묶음 전체에 걸린다. 그래서 #313·#314가 모든 경우를 덮는다. 문제 없다.
     - **장면 제목:** 조건이 없는 장면 제목은 줄이 하나도 안 보여도 화면에 뜬다(아래 A-14).
- **판정:**
  - **오류:** 사실·인과·정보·조건·동선·시간이 어긋난다. 반드시 고친다.
  - **어색함:** 말이 되지만 부자연스럽다.
  - **연동:** 9·10·11장 판정과 맞춰야 하는 곳이다.
  - **작가 결정:** 방향을 골라야 한다.

**요약:** 오류 31건, 어색함 29건, 연동 5건, 작가 결정 1건.
