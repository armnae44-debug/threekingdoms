## 2. 최근에 고친 것

**화면**
- 위쪽 인장 줄: 장 번호 낙관, 지명 붓글씨, 조공의 시선, 명부·아는 것·사서·메뉴 아이콘
- 글 칸 아래: 지나간 본문 · 자동(A 키) · 빨리(F 키, 본 글만 넘김)
- 창 위쪽 탭: 나 · 명부 · 아는 것 · 사서 · 기록 · 설정. 같은 기능이 여러 곳에 흩어져 있던 것을 한 곳씩으로 정리
- 휘하 창을 명부에 합침. 대쪽을 누르면 함께한 일이 보임
- `책에 적힌 결말`을 `아는 것` 창 맨 위로 옮김
- 닫기 버튼이 안 눌리던 문제 (창 제목이 버튼을 덮고 있었음)
- PC 족자는 글이 위에서부터 참. PC 선택지에 바탕 판을 깔고 설명 줄이 늘 보이게 함
- 장 끝 카드 겹침, 장 이동(가 본 장만 고를 수 있게), 시작 메뉴와 인물 창 크기
- 기록 칸에 장면 그림, 몇 장·어디, 마지막 문장이 보임
- 화면 끊김: 한 장면 그리는 시간 167ms → 51ms

**문구**
- 조공의 시선: "조공이 내 이름을 안다. 내 부탁이 통한다. 8칸이 되면 나를 시험한다"처럼 칸과 뜻만 적음
- 신뢰: 신뢰 없음 / 조금 / 보통 / 높음 / 매우 높음 / 등을 돌림
- "~을 기억한다" 알림 16곳을 있었던 일 그대로 적는 문장으로 바꿈
- 사서 표시: 책대로 됐다 / 책대로 됐다. 내가 끼어들었다 / 소문과 달랐다 / 내가 바꿨다

## 4. 추천 순서

1. **선택지·미니게임**(남은 일 1). 대본만 확인해 주시면 바로 넣을 수 있고, 게임이 가장 크게 달라지는 일입니다.
2. **결말 화면**(남은 일 2). 하루 안에 끝납니다.
3. **그림·음악**은 받는 대로 붙입니다. 미니게임 그림 3장(`paper_plan`, `aim_field`, `triage_bg`)이 먼저 오면 미니게임을 그림과 함께 넣습니다. 늦어지면 임시 화면으로 먼저 넣습니다.
4. **번역 준비 → Steam 묶기.** 출시 순서는 전에 말씀드린 대로 중국어(간체) → 영어 → 일본어를 추천합니다.

## 5. 번역 준비 방법 (남은 일 5)

1. 게임 전체의 한국어 문장을 `lang/ko.json` 표 하나로 뽑습니다.
2. 언어별 표(`zh.json`, `en.json`, `ja.json`)를 만듭니다. 초안은 제가 쓰고, 출시 전에 원어민 검수를 한 번 받는 것을 권합니다.
3. 게임이 글을 띄울 때 고른 언어의 표에서 찾아 바꿉니다. 대사, 선택지, 알림, 메뉴가 모두 해당됩니다.
4. 1~4장에서 이름을 끼워 넣는 문장 11곳과 조사를 고르는 곳 7곳만 따로 고칩니다.
5. 설정에 언어 선택을 넣고 중국어·일본어 글꼴을 붙입니다.
