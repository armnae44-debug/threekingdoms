# 전체 통독 점검 (1장~13장, A·B 두 갈래)

## 읽은 범위

- 1~4장: 자동 플레이 두 판(서로 다른 선택)의 전체 기록
- 5~13장: A갈래 한 판, B갈래 한 판의 전체 기록
- 기록에 찍힌 대사와 서술을 한 줄씩 읽었다. 장 번호는 게임 화면 기준이다.

## 결론: 완벽하지 않다

중간 이후는 많이 좋아졌다. 그래도 고쳐야 할 것이 아래만큼 남아 있다.

## 4. 격언처럼 말하는 대사

사람 입에서 나와도 격언 투가 겹치면 설교로 들린다. 관우는 한 장면에 세 번이다.

| 장 | 대사 | 제안 |
|---|---|---|
| 5장A 관우 | "은혜는 갚으면 끝나는 것이고, 의리는 갚아도 끝나지 않는 것이오." / "춘추는 누가 이겼는지를 적은 책이 아니오…" / "난세에 싸움 잘하는 사람은 많소. 하지만…" | 셋 중 '춘추' 하나만 남긴다. 나머지는 곳간 이야기(구체적 사례)로 대신한다. |
| 8장·11장 저수 | "모르는 것을 안다고 말하는 순간부터 군대가 위험해진다." (서술과 대사에 두 번) | 대사 한 번만 남긴다. |
| 1장 조노 | "졸병은 눈에 안 띄는 게 오래 사는 법이오." | 조노 말투라 둔다. |
| 2장 | "좋은 말도 있었고, 아닌 말도 있었다. 아닌 말이 더 오래 갔다." | "칭찬은 사흘 갔다. 뒷말은 한 달 갔다." |
| 11장A 장합 | "항복하는 자의 칼은 받는 사람이 있어야 하오." | "받으시오. 그래야 내 병사들이 창을 거꾸로 쥐오." |
