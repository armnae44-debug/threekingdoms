# 8번 · 9번 방안

## 8번. 2장 시작 전에 뜨는 `책에 적힌 결말`

**지금 문제**
- 1장이 끝나자마자 조앙·전위·여포·저수의 죽음이 한꺼번에 뜹니다.
- 플레이어는 이때 저수가 누군지 모릅니다. 저수는 8장 막간에 처음 나옵니다.
- 설명 없이 갑자기 떠서 "이게 뭐지?" 하게 됩니다.

**방안: 하나씩 떠오르게 하기 + 처음에 두 줄 설명**

| 언제 | 목록에 더해지는 사람 | 이유 |
|---|---|---|
| 1장 끝 | 조앙, 전위 | 바로 다음 큰 사건이 3장 완성입니다 |
| 3장 끝 (하비로 가기 전) | 여포 | 4장 하비에서 바꿀 수 있습니다 |
| 8장 막간에서 저수가 처음 나온 뒤 | 저수 | 이름과 얼굴을 안 뒤에 보여 줍니다 |

- 조노·왕삼·소칠 줄("책에 이름이 없다")은 처음부터 둡니다.
- 처음 뜰 때 목록 위에 두 줄을 넣습니다.
  > 퇴근길에 읽던 책 내용이 떠올랐다.
  > 이 사람들이 언제, 어떻게 죽는지 책에 적혀 있었다.
- 사람이 더해질 때는 알림을 띄웁니다: `아는 것 · 여포가 어떻게 죽는지 떠올랐다`.
- `아는 것` 창에도 떠오른 사람만 보입니다.
- 이미 그 장을 지난 저장 기록을 불러오면, 그 장까지의 사람은 바로 다 보입니다.

## 9번. 선택지 없이 읽기만 하는 긴 구간

5~12장을 A·B선으로 4판씩 돌려서, 선택지 사이가 7분을 넘는 곳을 쟀습니다. 읽는 시간은 줄마다 1.5초 + 아홉 글자에 1초로 셌습니다.

| 장 | 갈래 | 구간 (어디서 → 다음 선택지) | 길이 |
|---|---|---|---|
| 12장 | A | 관도 결전 후반 "들것을 지킬 병사들은 남아!" → `아홉 이름` | **약 11~12분** |
| 12장 | A | 저수 쪽 막간 (본진으로 돌아온 저수) → 관도 | 약 9분 |
| 12장 | B | "나는 군관에게 알렸다" → `승전` | 약 9분 |
| 7장 | A·B | `2. 벽력` 마지막 선택 → `3. 남은 망루` | 약 9분 |
| 7장 | A·B | `3. 남은 망루` 안 (발석거 그림을 그리는 대목) | 약 8~9분 |
| 7장 | B | `4. 첫 돌을 기다리는 사람들` 안 | 약 8분 |
| 5장 | B | 백마 전투 "오른쪽! 저 창병들 앞을 막아!" → `승전의 밤` | 약 9분 |
| 6장 | B | 연진 "다들! 온후 뒤로 붙어!" → `포상` | 약 8분 |
| 11장 | B | `돌아올 사람들` 대화 → `삼백 명` | 약 7.5분 |

**목표**: 선택지 사이가 5분을 넘지 않게 합니다.

**방안: 줄거리는 그대로 두고, 가벼운 선택지를 구간 한가운데에 하나씩 넣기 (9~10곳)**

새 갈래는 만들지 않습니다. 고른 것에 따라 대사 한두 줄과 신뢰·시선만 조금 달라집니다. 이미 있는 장치만 씁니다.

| 구간 | 넣을 선택지 (예) | 결과 |
|---|---|---|
| 12장 A 결전 후반 | 들것 옆에 남는다 / 앞줄로 나간다 | 남으면 조노 신뢰 +, 나가면 다음 장면 대사 한 줄이 바뀜 |
| 12장 A 저수 막간 | (주인공이 없는 막간이라 선택지를 못 넣습니다) | 막간을 둘로 나눠 앞뒤 장면 사이에 끼웁니다 |
| 12장 B 승전 전 | 군관에게 알린 뒤: 직접 확인하러 간다 / 자리를 지킨다 | 대사 몇 줄, 시선 +1 여부 |
| 7장 벽력 → 망루 | 다친 병사를 먼저 옮긴다 / 덮개부터 고친다 | 왕삼 또는 소칠 신뢰 + |
| 7장 남은 망루 | 그림을 누구에게 먼저 보일지: 두석 / 유엽 | 대사 몇 줄, 유엽 쪽이면 시선 +1 |
| 7장 첫 돌을 기다리며 | 기다리는 동안: 부상병 곁 / 망루 위 | 다음 장면 첫 줄이 바뀜 |
| 5장 B 백마 전투 | 창병 앞을 누구에게 맡길지: 왕삼 / 소칠 | 그 사람 신뢰 +, 승전의 밤 대사 한 줄 |
| 6장 B 연진 | 여포 뒤 대열에서: 앞줄 / 뒷줄 | 포상 장면 대사 한 줄 |
| 11장 B 돌아올 사람들 | 대답하는 태도: 고맙다고 한다 / 말없이 듣는다 | 대사 몇 줄 |

**만드는 순서**
1. 위 9곳의 선택지와 고른 뒤 대사를 대본 md로 먼저 씁니다.
2. 확인을 받은 뒤 게임에 넣습니다.
3. 다시 재서 5분을 넘는 구간이 남았는지 확인합니다.

다른 방법으로, 긴 구간의 글을 20~30% 줄이는 것도 있습니다. 다만 대본을 여러 번 검수한 뒤라서, 선택지를 넣는 쪽을 추천합니다.
