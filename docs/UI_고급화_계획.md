# 관도지로: UI 고급화 계획

## 0. 렉 (고침, 커밋 567bf05)

인물이 서는 장면에서 한 장면을 그리는 데 걸리는 시간을 쟀습니다. 고치기 전에는 167ms(초당 6장)였고, 고친 뒤에는 51ms입니다. 고친 전후 화면은 거의 같습니다.

| 원인 | 고친 방법 |
|---|---|
| 인물이 서면 배경 전체에 흐림·밝기 필터를 걸었습니다. 그 배경이 천천히 움직이는 애니메이션(38초)까지 돌고 있어서 매 장면 화면 전체를 다시 흐렸습니다 | 흐림을 빼고, 배경 위에 반투명 검은 막을 한 장 깝니다 |
| 인물 그림에 그림자 필터가 두 겹 걸려 있었습니다 | 그림자를 미리 그려 넣은 인물 그림 45장(`assets/portrait_s/`)을 씁니다. 만드는 도구: `tools/portrait_shadow.py` |
| 불티가 초당 30번 그려졌습니다 | 불 장면만 초당 30번, 나머지 장면은 초당 8번 그립니다 |

## 3. 바꿀 내용

### 3-1. 위쪽 줄 → 인장 줄

```
[第六章 낙관]  연진           (눈) 조공의 시선 ◉◉◉◉◉○○○○○○○     [죽간] [두루마리] [책]  [≡]
```

- 왼쪽: 장 번호를 붉은 낙관 안에 넣고, 옆에 지명을 붓글씨로 씁니다.
- 가운데: 조공의 시선. 눈 아이콘을 붙이고, 점 12개를 청동 고리 모양으로 바꿉니다. 4·8·10칸 문턱에 작은 금 표시를 둡니다. 칸이 오르면 붉게 한 번 번집니다.
- 오른쪽: 명부(죽간), 아는 것(두루마리), 연대기(책) 세 버튼을 아이콘으로 둡니다. 마우스를 올리면 이름과 단축키가 뜹니다. 새 내용이 생기면 붉은 점이 붙습니다.
- 평소에는 70% 밝기로 두고, 마우스를 올리거나 휴대폰에서 누르면 밝아집니다.

### 3-2. 글 칸 아래 → 빠른 버튼 줄

`지나간 본문 · 뒤로 읽기 · 저장 · 불러오기 · 설정 · 장 이동`을 작은 아이콘으로 한 줄에 둡니다.

- **새 기능 제안**: `자동`(글을 저절로 넘김)과 `빨리`(이미 본 글은 건너뜀)를 넣을 수 있습니다. 지금 게임에는 없는 기능입니다. 다시 하는 판에서 특히 쓸모가 있습니다.

### 3-3. 명부 → 인물 카드

- 죽간 위에 얼굴(동그란 액자)을 올립니다.
- 사이는 옥구슬 4개로 보여 줍니다. 지금은 점과 글로만 보여 줍니다.
- 다치면 붉은 `傷` 도장, 죽으면 회색으로 바꾸고 `歿` 도장을 찍습니다. `歿` 도장 그림은 이미 있습니다.
- 사람을 누르면 지금까지 함께한 일을 한 줄씩 보여 줍니다(이미 있는 기록을 씁니다).

### 3-4. 창(메뉴·휘하·아는 것·연대기)

- 어긋나 보이는 두 겹을 고칩니다. 화면 전체를 한 번만 어둡게 덮고, 족자 하나만 띄웁니다.
- 창 위쪽에 탭을 두어 명부·아는 것·연대기·설정을 오갈 수 있게 합니다. 지금은 창마다 닫고 다시 열어야 합니다.
- 빈 상태에는 먹 그림 하나와 문장 하나(예: "아직 내 휘하에 선 사람이 없다.")를 둡니다.

### 3-5. 알림

위쪽 줄 아래, 왼쪽 그림 칸 안에 띄웁니다. 버튼을 덮지 않게 하고, 3초 뒤 사라집니다. 휴대폰에서는 글 칸 바로 위에 띄웁니다.
