# 7·8장 최종 문제 목록

- 범위: 7장(관도 토산·벽력거), 8장(발밑, A·B 두 갈래). 모든 줄을 조건과 함께 읽고, 선택지 조건은 데이터에서 직접 확인했습니다.
- 줄 번호는 화면 대본의 `#번호`입니다(`7장` = 데이터 CH8, `8장A` = 9A, `8장B` = 9B).
- **결과: 확실한 문제는 7건입니다.** 100건을 채우려고 늘리지 않았습니다.
- 고칠 안은 앞뒤 줄, 높임말, 조건과 맞춰 읽었고, 바로 앞뒤 문장과 같은 말이 겹치지 않는지도 확인했습니다.

| 분류 | 건수 | 번호 |
|---|---|---|
| A. 앞뒤가 맞지 않음 | 4 | 1, 2, 3, 4 |
| B. 선택지와 본문이 어긋남 | 2 | 5, 6 |
| C. 지워진 줄이 남긴 흔적 | 1 | 7 |

## A. 앞뒤가 맞지 않음

### 1. 7장 유엽: 장인에게 넘긴 나무자로 다시 가리킴

조건: `yuTalk=smoke`

| | 줄 |
|---|---|
| #129 | 유엽은 장인에게 **들고 있던 나무자를 건네고** 내 말을 들었다. |
| #137 | 나: 취사장입니다. 밥 짓는 연기만 올라도 그쪽으로 쏩니다. … |
| #138 | 유엽: 연기 오르는 곳이 보이는 망루라면… 저것과 저것이군. |
| #139 | 그는 **나무자로** 망루 쪽을 가리켰다. |

문제: 나무자는 #129에서 장인에게 넘겼습니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #139 | 그는 나무자로 망루 쪽을 가리켰다. | 그는 손가락으로 망루 쪽을 가리켰다. |

### 2. 7장 `시험이 끝날 때까지 남는다`: 고리 이야기를 한 날이 "어젯밤"이 아님

조건: `c2=1`

| | 줄 |
|---|---|
| #498 | **그날 저녁** 유엽이 조홍에게 나를 며칠 더 빌려 달라고 청했다. (선택 c2) |
| #511 | **그날 밤** 유엽과 그림을 다시 펼쳤다. 돌을 담은 줄의 고리가 팔 끝에서 빠지는 때를 두고 오래 이야기했다. … |
| #513 | **다음 날 밤** 적진에 불이 났을 때도 나는 작업장에 있었다. |
| #528 | 병사들이 눕는 것을 보고 작업장으로 돌아갔다. **다음 시험**에서는 돌이 더 멀리 날아갔다. |
| #530 | 유엽: **어젯밤** 그대가 말한 고리요. 팔 끝의 쇠를 조금 눕혔더니 돌이 늦게 빠지오. |

문제: 고리 이야기는 야습 전날 밤(#511)에 했습니다. 시험은 야습한 밤(#513) 뒤에 하므로, 유엽에게 "어젯밤"은 야습한 밤입니다. 그날 밤 나는 부상자를 받고 있었습니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #530 | 유엽: 어젯밤 그대가 말한 고리요. … | 유엽: 그저께 밤 그대가 말한 고리요. … (뒤는 그대로) |

### 3. 8장A 저수: 붙잡힌 사람이 둘인 갈래에서도 "하나"

조건: 모든 갈래. 문제가 되는 것은 `a9_rescue=back`일 때입니다.

| | 줄 | 조건 |
|---|---|---|
| #51 | 옆 구간에서는 **장오와 이석이** 땅을 파고 있었다. | |
| #175 | 이석은 끌려가고 있었고, 장오는 그 옆에서 걸었다. | back |
| #179 | 나: 둘입니다. 장오와 이석입니다. | back |
| #235 | 다만 그 도랑을 판 구간에서 붙잡혀 온 병사가 **하나** 있었다. | 모두 |
| #240 | 장오: **같이 잡혀 온 사람**은 어디 있습니까. 걷지도 못합니다. | back |

문제: `back` 갈래에서는 같은 구간을 판 장오와 이석이 둘 다 잡혀 왔고, 장오도 바로 그 말을 합니다. `go` 갈래(장오만 잡힘)에서는 맞는 문장입니다.

고침: 두 갈래 모두에 맞게 수를 빼고, 저수 앞에 앉은 사람이 하나라는 뜻만 남깁니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #235 | 다만 그 도랑을 판 구간에서 붙잡혀 온 병사가 하나 있었다. | 다만 그 도랑을 판 구간의 병사가 붙잡혀 와 있었다. |

다음 줄 #237 "저수는 붓을 내려놓았다." → #239 "붙잡혀 온 병사는 저수 앞에 앉아서도 문 쪽만 보고 있었다."와 이어집니다.

### 4. 7장 물 긷기 `내가 간다`: 물통을 들지 않은 내가 "물통을 쥔 손등"을 다침

조건: `w=self`

| | 줄 |
|---|---|
| 선택지 | 내가 간다 — **병사 둘에게 물통을 지우고**, 방패 하나를 붙여 직접 앞장선다 |
| #90 | 나는 **빈 물통을 진 병사 둘**을 데리고 앞장섰다. 왕삼이 방패를 들어 내 머리 위를 가렸다. |
| #92 | … 화살 하나가 방패 가장자리 아래로 들어와 **물통을 쥔 손등**을 긁었다. |

문제: 주어가 없어서 내 손으로 읽히는데, 나는 물통을 들지 않았습니다.

고침: 물통을 진 병사의 손으로 밝힙니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #92 | …방패 가장자리 아래로 들어와 물통을 쥔 손등을 긁었다. | …방패 가장자리 아래로 들어와 물통을 진 병사의 손등을 긁었다. |

## B. 선택지와 본문이 어긋남

### 5. 7장 전위·전만에게 다시 숨기는 선택지: 전위 갈래에도 "전만 앞에서"

조건: `dq_ans=lie` (5장에서 모른다고 거짓말한 경우). 전위가 살아서 묻는 갈래와 전만이 묻는 갈래가 같은 선택지 하나를 씁니다.

| | 줄 |
|---|---|
| #400~404 (`dq=dianwei`) | 전위: 그날 물은 거, 다시 묻는다. … 정말 몰랐냐? |
| #408 선택지 | 몰랐다고 한 번 더 감춘다 — **전만 앞에서** 다시 거짓말을 한다 |
| #428 (`dq=dianwei`) | 나: 몰랐습니다. |

문제: 전위가 묻는 갈래에서도 선택지 설명에 "전만 앞에서"가 나옵니다. 데이터에는 이 선택지가 하나뿐이고, 코드에서 따로 바꾸는 곳도 없습니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| 선택지 jw `deny` 설명 | 전만 앞에서 다시 거짓말을 한다 | 같은 거짓말을 한 번 더 한다 |

### 6. 8장B 오소 `짚어 말한다`: 선택지와 내 말, 순유의 대답이 서로 다름

조건: `b9_wuchao=point`

| | 줄 |
|---|---|
| 선택지 | 오소가 원소군의 곡식이 모이는 곳이라고 짚어 말한다 — **이 수레만 가는 곳인지, 다른 곡식도 그리로 모이는지 캐 보자고** 먼저 청한다 |
| #301 | 나: 이자가 실어 가던 곳이 오소라고 합니다. **오소가 어디 있는지, 누가 지키는지부터** 캐 주셨으면 합니다. |
| #302 | 순유: 좋소. **다른 짐꾼들한테도 같은 걸 물어 맞춰 봅시다.** 한 사람 말로는 모르니. |
| #303 | 나: **곡식이 모인 곳이면**, 한 번에 태울 수 있지 않겠습니까. |

문제: 선택지와 #302·#303은 "다른 곡식도 그리로 모이는지"를 전제로 하는데, #301만 "어디 있는지, 누가 지키는지"를 묻습니다. 같은 장면의 8장A #212는 선택지와 맞게 쓰여 있습니다.

고침: 8장A #212와 같은 문장으로 맞춥니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| 8장B #301 | 나: 이자가 실어 가던 곳이 오소라고 합니다. 오소가 어디 있는지, 누가 지키는지부터 캐 주셨으면 합니다. | 나: 이자가 실어 가던 곳이 오소라고 합니다. 이 수레만 가는 곳인지, 다른 곡식도 그리로 모이는지 캐 주셨으면 합니다. |

## C. 지워진 줄이 남긴 흔적

### 7. 7장 시험 거리: "그러면"이 받을 말이 없음

조건: `c1=2` 또는 `c1=3` (출처를 말할 수 없다고 했거나, 서역 그림이라고 한 경우)

| | 줄 |
|---|---|
| #462 | 조홍의 군관이 돌이 떨어진 곳까지 거리를 적었다. |
| (#466~469 숨김) | ~~유엽: 그대가 본 것은 이보다 멀리 던졌소? / 나: …장담하지 못하겠습니다.~~ |
| #470 | 유엽: **그러면** 우리가 쏜 거리로 맞춰 갑시다. |

문제: 예전에 유엽의 물음과 내 대답(#466~469)을 숨기면서 "그러면"만 남았습니다. 지금은 서술 바로 뒤에 "그러면"이 옵니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #470 | 유엽: 그러면 우리가 쏜 거리로 맞춰 갑시다. | 유엽: 이제부터는 우리가 쏜 거리로 맞춰 갑시다. |
