# 1~4장 그림 깃발 고치기

> 1~4장 배경 그림 30장을 다 확인했다. 깃발에 서양식 용 문양이 들어간 그림은 **완성(3장) 10장, 하비(4장) 6장**이다.
> 1장(복양)·2장(연주·허도) 그림은 깃발이 무늬 없는 천이거나 아주 작게 나와서 그대로 둬도 된다.
> 다시 그리기보다 **원래 그림을 넣고 깃발 부분만 고쳐 그리기(부분 수정)**를 쓰는 게 낫다. 구도와 분위기가 그대로 남는다.

---

## 깃발 기준 (5장 이후 그림과 똑같이)

**조조군 깃발**
- 세로로 긴 직사각형 천. 짙은 남색에 가까운 검은 바탕.
- 가운데에 금색 붓글씨로 한자 **曹** 한 글자.
- 깃대 위쪽 가로대에 매달려 있고, 아래쪽에 검은 천 꼬리 두세 가닥이 바람에 날린다.
- 용, 짐승, 문장(紋章) 같은 그림은 **절대 넣지 않는다.**

**상대편 깃발** (같은 그림에 함께 나올 때)
- 장수 군(완성 성벽): 붉은 바탕에 검은 글씨 **張**
- 여포군(하비 성벽, 함락 전): 붉은 바탕에 검은 글씨 **呂**

**공통 프롬프트 (부분 수정 때 붙여 넣기)**
> 깃발의 용 문양을 지우고, 짙은 남색에 가까운 검은 깃발 가운데에 금색 붓글씨 한자 '曹' 한 글자만 넣어 주세요. 깃발 모양은 세로로 긴 직사각형이고, 아래에 검은 천 꼬리가 두세 가닥 바람에 날립니다. 용, 동물, 서양식 문장은 넣지 마세요. 그림의 다른 부분은 바꾸지 마세요.

## 고칠 그림 목록

### 3장 · 완성

| 파일 | 장면 | 고칠 깃발 |
|---|---|---|
| `ch4_camp.webp` | 완성 입성, 조조군 진영 | 왼쪽 앞 남색 용 깃발 3개 → **曹**. 뒤쪽 성문 위 붉은 깃발 → **張** (아직 장수의 성이다) |
| `ch4_feast.webp` | 사흘째 연회 | 뒤쪽 붉은 용 깃발들 → 붉은 바탕 **曹**(연회는 조조가 연다). 용 무늬 장막도 무늬 없는 천으로 |
| `ch4_night.webp` | 습격 전 밤의 진영 | 왼쪽·오른쪽 남색 용 깃발 → **曹** |
| `ch4_smithy.webp` | 대장간 뒤 | 위쪽 남색 용 깃발 2개 → **曹** |
| `ch4_stable.webp` | 마구간 | 오른쪽 남색 용 깃발 2~3개 → **曹** |
| `ch4_tent.webp` | 조조의 군막 안 | 벽에 걸린 남색 용 깃발 2개 → **曹**, 밖에 보이는 작은 깃발도 **曹** |
| `ch4_fire.webp` | 야습, 불타는 진영 | 왼쪽 불붙은 남색 용 깃발 → 불붙은 **曹** 깃발 |
| `ch4_river.webp` | 강을 건너 퇴각 | 왼쪽 위·가운데 남색 용 깃발 → **曹** |
| `ch4_campfire.webp` | 강가 화톳불 | 뒤쪽 어두운 깃발들 → **曹** |
| `ch4_dawn.webp` | 퇴각 다음 날 새벽 | 왼쪽 남색 용 깃발 2개 → **曹** |

### 4장 · 하비

| 파일 | 장면 | 고칠 깃발 |
|---|---|---|
| `ch5_camp.webp` | 하비 포위, 조조군 진영 | 왼쪽 남색 용 깃발 → **曹**. 성벽 위 붉은 깃발 → **呂** |
| `ch5_field.webp` | 성 앞 들판 | 왼쪽 남색 용 깃발 3개 → **曹**. 성벽 위 붉은 깃발 → **呂** |
| `ch5_river.webp` | 물길 공사 | 왼쪽 남색 용 깃발 2개 → **曹** |
| `ch5_flooded.webp` | 물에 잠긴 하비 | 왼쪽 앞 깃발 → **曹**. 성문 위 붉은 깃발 → **呂** |
| `ch5_gate.webp` | 백문루, 여포를 끌고 나옴 | 성은 이미 함락됐다. 붉은 용 깃발 전부 → 붉은 바탕 **曹**. 계단 앞 용 장식도 무늬 없이 |
| `ch5_tent.webp` | 조조의 군막 회의 | 벽의 남색 용 깃발 → **曹**, 밖의 작은 깃발도 **曹** |

### 그대로 둬도 되는 그림
- `ch5_night.webp`: 장막 무늬가 흐릿해서 깃발로 안 보인다. 거슬리면 장막 무늬만 지운다.
- `ch5_paddy.webp`: 멀리 성벽 깃발이 점처럼 보인다.
- 1~3장 전부(`ch1_*`, `ch2_*`, `ch3_*`): 무늬 없는 천 깃발이다.
