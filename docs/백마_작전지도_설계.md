# 백마 · 작전 지도 전투 — 설계

장료의 군막에 펼친 작전 지도 위에서 부대 패를 움직여 지휘한다. 병사를 하나하나 그리지 않는다.

## 1. 화면

| 자리 | 무엇 |
|---|---|
| 가운데 (화면 대부분) | 종이 지도. 먹으로 그린 길, 물가, 둑, 북쪽의 안량 진영, 남쪽의 우리 진영 |
| 지도 위 | 나무 패: 옻칠 바탕에 붓글씨 盾·槍·弓·騎와 인원. 원소군 패는 주사 바탕 |
| 지도 위쪽 | 안량의 군기와 본진 패. 우리 기병 패가 그쪽으로 얼마나 파고들었는지 먹선으로 보인다 |
| 오른쪽 아래 | 전령 카드: 말하는 사람 얼굴 그림(왕삼·조노·소칠·장료, 이미 있는 그림)과 보고 한 줄 |
| 아래 | 고른 부대의 진형·명령, 남은 화살 |

움직임은 이렇게 보인다.
- 패가 움직이면 먹선이 그어진다.
- 맞붙은 곳에는 먹이 번지는 접전 자국이 생긴다.
- 화살은 가는 먹 점선이 비처럼 떨어진다.
- 패가 깎이면 숫자가 줄고, 무너지면 패가 쓰러진다.

## 2. 판의 흐름

1. **출격** (0초)
   - 장료와 관우(또는 여포)의 기병 패가 우리 대열 사이로 길을 따라 북쪽으로 달려 나간다.
   - 그 뒤 기병은 지도 위쪽에서 안량 쪽으로 파고든다.
2. **떠보기**
   - 안량의 선봉 창병이 길목으로 내려온다.
   - 적 궁수가 자리를 잡는다.
3. **기병 귀환** (세 번)
   - 앞에서 싸우던 기병 가운데 말에서 떨어진 자들이 길을 따라 돌아온다.
   - 뒤에 적 추격대가 붙는다.
   - 출격 장면이 있으니 북쪽에서 돌아오는 게 자연스럽다.
4. **본대 압박**
   - 안량이 가장 약한 곳을 찌른다.
   - 왼쪽과 오른쪽 옆 부대에도 적이 나뉘어 들어간다.
5. **우회**: 오른쪽 둑 너머로 적이 돌아 관우 기병의 뒤를 노린다.
6. **돌파**: 우리 기병 패가 안량 군기에 닿으면 끝난다.

## 3. 병력

| 쪽 | 부대 |
|---|---|
| 우리 | 내 부대 200 (편성 4개, 지휘관 왕삼·조노·소칠·나) |
| 옆 부대 (자동) | 왼쪽 보병 150, 오른쪽 보병 150. 버티다 밀리기도 한다 |
| 우리 기병 (자동) | 장료·관우(여포) 기병. 지도 위쪽에서 안량 쪽으로 파고든다 |
| 원소군 | 안량 본진(친위대), 선봉 창병 둘, 궁수, 추격 기병, 우회대. 전체 600 남짓. 우리 길목에 오는 건 그중 일부 |

적장 쪽 부대 이름은 역할로 붙인다. 예: "안량 친위대", "선봉 창병", "우회대". 사서에 없는 이름은 짓지 않는다.

## 4. 명령

| 명령 | 누가 | 하는 일 |
|---|---|---|
| 이동 | 전부 | 지도를 눌러 보낸다 |
| 공격 | 전부 | 적 패를 눌러 그 부대를 치러 간다. **명령 없이는 쫓아가지 않는다.** 붙으면 막기만 한다 |
| 진형: 방진 | 방패·창 | 막는 힘이 크게 오른다. 움직이지 못한다 |
| 진형: 횡대 | 전부 | 넓게 선다. 옆을 덜 뚫린다. 정면은 얇다 |
| 진형: 밀집 | 전부 | 좁고 두껍다. 한가운데가 안 뚫린다. 화살에 약하다 |
| 창 세우기 | 창 | 기병이 들이받으면 기병이 크게 다친다. 그동안 움직이지 못한다 |
| 일제 사격 | 궁수 | 한 번에 크게 맞히고 적 사기를 꺾는다. 화살을 많이 쓴다 |
| 물러나기 / 교대 | 전부 | 숙련이 낮으면 적과 붙은 채로는 늦게 빠진다 (조노가 있으면 덜하다) |

## 5. 궁수

- 화살은 부대당 열두 묶음이다.
  - 보통 사격은 한 묶음을 쓴다.
  - 일제 사격은 세 묶음을 쓴다.
  - 다 쓰면 쏘지 못한다.
- 앞에 아군이 있으면 넘겨 쏜다. 위력은 70%다.
- 방패 없는 창병과 기병에게 잘 든다. 방패병은 화살을 막는다.
- 지금보다 위력을 서너 배 올린다. 궁수가 판을 바꿀 수 있어야 한다.

## 6. 지휘관 (행동으로 보인다)

- **왕삼**: 무너질 때 한 번 대열을 다시 세운다. 전령 카드에 얼굴과 함께 "물러서지 마라!"
- **조노**: 물러나기와 교대 때 덜 흩어진다. 흩어진 부대를 빨리 수습한다.
- **소칠**: 기병 귀환과 우회를 더 일찍 알린다.
- **나**: 내 부대는 명령이 빠르다. 멀리 있는 부대에는 명령이 늦게 닿는다.

## 7. 승패

- 위쪽에서 **우리 기병 패가 안량 군기까지 얼마나 갔는지**가 남은 시간 대신 보인다.
- 길목이 흔들리거나 우회를 놓치면 기병의 전진이 느려진다.
- 끝났을 때 서 있는 병력으로 판정한다.

| 서 있는 병력 | 결과 |
|---|---|
| 70% 이상 | 守 · 길목을 지켰다 |
| 45~70% | 守 · 값비싸게 지켰다 |
| 45% 미만, 또는 적이 길목을 90명 넘게 지나감 | 潰 · 길목이 무너졌다 |

## 8. 만들지 않는 것

- 병사 하나하나의 그림
- 새로 뽑을 그림. 지도는 코드로 종이와 먹 질감을 낸다. 인물 얼굴은 이미 있는 그림을 쓴다.
