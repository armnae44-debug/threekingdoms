# 11~12장 반영 전후 — 바뀐 줄 전부

- `- 전`은 고치기 전, `+ 후`는 고친 뒤다. `앞`·`뒤`는 고친 뒤의 바로 앞뒤 줄이다.
- 번호(#)는 고친 뒤 덤프의 데이터 번호다. 줄을 넣은 곳에서는 뒤 번호가 밀린다.
