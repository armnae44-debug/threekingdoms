# 7장 검수 비교 — 외부 검수 vs 내 재검수

외부 검수는 네 묶음이다.
1. 내 수정안 비판 14개
2. 내 수정 문장 비판 10개
3. 원문 지적 15개 + 문장 표 + 철회 목록
4. 추가 4개

모든 항목을 7장 실제 본문(`CH8_DATA` 덤프 #1–776)과 줄마다 대조했다. 갈래 조건도 같이 봤다.

## 0. 결론

| 구분 | 수 |
|---|---|
| 외부가 맞고, 내 수정안·수정 문장이 틀린 것 | 20 |
| 외부가 맞고, 내 출처 표기가 틀린 것 | 3 |
| 내가 오류로 과하게 판정한 것 (철회·낮춤) | 10 |
| 외부가 찾았고 내가 놓친 원문 문제 | 17 |
| 둘 다 찾은 원문 문제 (내 고침 방향은 외부 쪽이 낫다) | 12 |
| 외부 지적 중 일부만 맞는 것 | 4 |
| 외부 지적 중 틀린 것 | 0 |
| 나만 찾은 것 (외부에 없음) | 3 |

이번에는 외부 검수가 훨씬 정확했다. 특히 내 수정안이 **문제를 고치면서 새 사실(인물이 아는 범위, 지어낸 사건)을 덧붙이는** 버릇을 정확히 짚었다. 그래서 1-추가를 포함한 내 수정안 표는 그대로 반영하면 안 된다. 아래 4절의 합친 목록으로 바꾼다.

## 3. 나만 찾은 것 (외부에 없음)

1. **왕삼과의 서먹함이 7장에서 소리 없이 풀린다 (`well=punish`).** 5·6장에서 이 갈래의 왕삼은 "내 쪽은 보지 않았다", "먼저 말을 걸지 않았다". 그런데 7장의 #19, #139, #156은 조건 없이 친하게 군다. #378–385에서는 내 밥을 챙겨 오고 웃으며 이야기한다. 외부는 "이번 장 안에서 화해시킬 필요 없다"고 했지만, 원문은 이미 화해한 것처럼 쓰여 있다.
   - 고침: #378 앞, `well=punish`·왕삼 생존 조건에 다음을 넣는다. "그는 그릇만 놓고 바로 돌아서려 했다." #385 "조노가 그릇까지 가져오라고 했소"는 그대로 둔다(심부름 이유가 조노다). 친한 대화 #379–383은 `!well=punish`로 가린다.
   - #19, #139, #156은 넉 달이 지났으니 일과 대화로 두어도 된다.
2. **조노 대역 이름이 두 개다.** 조건으로 갈린 줄은 '고참병'(#39, #98, #113, #115)이다. 조건 없는 조노 줄(#140, #150, #159, #180, #462, #470, #533, #550, #585, #605, #620, #624, #708, #711)은 `c8Text`가 '노병'으로 바꾼다. 같은 사람이 '고참병'과 '노병'으로 오간다.
   - 외부 14번(역할을 먼저 정하라)의 실제 사례다. 대역 역할을 "고참병"으로 정하고 `c8Text`를 맞춘다.
   - 왕삼 대역 '방패병 군관'도 문제다. #431–434에서 "대신 부대를 맡을 군관"과 겹친다. **'방패병 고참'으로 바꾼다.**

## 5. 이번 비교에서 검수 방법에 더할 것

- **수정 문장 검사:** 고친 문장이 원문보다 인물이 아는 범위를 넓히지 않는지 본다. 사건을 새로 지어내지 않는지도 본다.
- **죽음·부상의 원인:** 선택한 뜻보다 큰 벌을 주지 않는지 본다. 선택 전에 보이지 않던 대가가 아닌지 본다.
- **출처:** 정사 열전·본기와 연의 회차를 따로 적는다. 후대 문헌을 그 시대의 근거로 쓰지 않는다.
- **판정 등급:** 연결 동작을 보완하면 되는 것, 말투, 요즘 말은 '어색함'이다. 오류로 세지 않는다.
