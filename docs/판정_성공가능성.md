# 판정 — 성공 가능성과 실패 장면

> **반영됨.** 선택지에 뜨는 "성공 가능성"은 실제 판정 확률을 그대로 보여 준다. 다친 곳이 하나 늘 때마다 8%씩 낮아진다.
> 표시: 70% 이상 "높음", 40% 이상 "반반", 그 아래 "낮음".

## 확률

| 자리 | 선택 | 성공 확률 |
|---|---|---|
| 2장 · 백부장 설득 | 장부가 곳간 회계와 안 맞는다고 따진다 | 50% (+25% 증거를 잡았을 때) |
| | 굶고 있는 부하 아홉을 앞세운다 | 30% |
| | 공을 백부장에게 돌린다 | 50% |
| | 공통 | 단서 둘 이상 +15%, 숫자로 셈 +10% / 막대로 셈 −5%, 목책 일로 백부장이 이름을 기억 +15% / 눈감아 준 빚 −15% |
| 3장 · 조앙 | 공자를 태우라고 주공께 외친다 | 40% (+20% 낮에 조앙과 말을 섞었을 때) |
| | 군마의 고삐를 낚아채 조앙에게 던진다 | 50% (+10% 무장했을 때) |
| 4장 · 사면장 | 후성 한 사람에게만 보내자고 한다 | 60% |
| | 세 장수에게 따로 보내자고 한다 | 45% + 지금까지 바꾼 일 하나마다 5% (최대 80%) |

## 실패했을 때 이어지는 장면 (새로 넣은 줄)

**백부장 설득 실패** — 위림에게 손을 다친 뒤
```
[조노 생존] 막사로 돌아오자 조노가 말없이 나뭇가지 두 개를 깎아 부목을 댔다.
[조노 생존] 조노: "손등뼈요. 붙기는 붙소. 한 달은 창을 제대로 못 쥘 거요."
[왕삼 생존] 왕삼은 그날 밤 위림의 막사 쪽을 오래 쳐다봤다. 나는 왕삼의 소매를 잡아 도로 앉혔다.
나(독백): 위림의 창고는 그 뒤로도 밤마다 수레를 내보냈다. 우리 솥은 그해 겨울 내내 묽었다.
```

**조앙 · 외치기 실패**
```
목이 터지도록 외쳤다. 불붙은 막사 하나가 무너지는 소리가 그 목소리를 덮었다.
조공의 고개가 한 번 이쪽으로 돌았다. 그러나 말은 이미 움직이고 있었다.
(조앙이 죽는 장면)
내 목소리는 조공에게 닿지 않았다. 조앙은 책에 적힌 그대로 죽었다.
```

**조앙 · 고삐 실패**
```
(고삐를 놓친다 → 조앙이 죽는 장면)
고삐를 놓친 손바닥에 말갈기 몇 가닥이 붙어 있었다. 조앙은 책에 적힌 그대로 죽었다.
```

**사면장 · 후성 한 사람 실패** — 병졸이 성벽에 매달린 뒤
```
순유: "이제 성 안에서는 화살 하나도 함부로 줍지 않을 거요. 물이 일을 마칠 때까지 기다리는 수밖에 없소."
그 뒤로 둑 위의 파수가 두 배로 늘었다. 우리 부대도 밤마다 둑에 올라 젖은 흙을 날랐다.
[조노 생존] 조노의 기침은 그 보름 사이에 더 깊어졌다. 밤이슬을 맞고 내려온 날은 새벽까지 기침이 멎지 않았다.
나(독백): 그 병졸은 화살을 주웠을 뿐이었다. 사면장을 쓰자고 한 사람 가운데 나도 있었다.
→ 서른나흘째 성문이 열린다
```

**사면장 · 세 장수 실패** — 하나가 진궁에게 편지를 바친 뒤
```
순유: "하나가 바쳤다면 남은 둘은 아직 망설이고 있는 거요. 진궁이 둘을 의심할수록 그 둘은 갈 데가 없어지오."
순유는 편지를 더 쓰지 않았다. 대신 성 안에서 잘 보이는 둑 위에 솥을 걸고, 먼저 넘어온 포로들을 배불리 먹였다.
나(독백): 셋이 한 밤에 움직였다면 더 일찍 끝났을 일이었다. 기다리는 동안 성 안에서도 밖에서도 사람이 죽었다.
→ 열여드레째 송헌과 위속이 여포를 묶는다
```
