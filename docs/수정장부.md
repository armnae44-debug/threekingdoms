# 수정 장부

외부 리뷰 약 110건과 추가 6건(L), 대조 중에 내가 찾은 3건(F7·K11·I2-추가)을 한 줄에 하나씩 적었다.

- **상태** 값:
  - 대기
  - 수정: 고쳤으나 검사 전
  - 확인됨: 검사 통과
- **검사** 값:
  - `문자열`: 옛 문장이 index.html에서 0개가 돼야 통과한다.
  - `플레이`: 그 갈래로 실제로 진행한 화면 글에 새 문장이 있고 옛 문장이 없어야 통과한다.
- **옛 문장** 칸은 검사 스크립트(scratchpad/ledger_chk.py)가 읽는다. 그래서 index.html에 실제로 있는 그대로 적었다.
