# 검수 방법

줄 단위로 보지 않는다. 사건 단위로 본다.

## 1. 사건 표부터 만든다

장을 읽기 전에 사건을 뽑는다. 예를 들어 5장은 우물, 전위·전만, 배치, 전투, 관우 대화, 배급이다.

사건마다 아래 칸을 채운다. 빈칸이 곧 지적이다.

| 칸 | 묻는 것 |
|---|---|
| 소개 | 이 사람·장소·직책을 플레이어가 언제 처음 봤나 |
| 계기 | 왜 하필 지금 일어나나 |
| 선택 전 정보 | 선택지에 나오는 사람·사정이 선택 **전에** 본문에 나왔나 |
| 선택 | 선택지가 실제로 다른 태도·행동인가, 질문에 대한 답인가 |
| 결과 | 갈래마다 결과가 실제로 다른가, 화면에 보이나 (전해 듣기만 하나) |
| 책임 | 시작한 사람(시비 건 병사, 칼 쥔 군관)이 끝까지 처리되나 |
| 위치 | 전투라면 다음 장면에서 부대가 어디 있나 |
| 나중 언급 | 뒷장면·뒷장이 이 결과를 맞게 부르나, 조건이 빠진 갈래는 없나 |

## 2. 갈래별로 끝까지 이어 읽는다

같은 사건을 선택값마다 한 번씩, 처음부터 끝까지 읽는다. 대체 인물(왕삼→고참, 소칠→신병)일 때도 따로 읽는다.

- 대체 인물에게 원래 인물의 과거나 반응을 그대로 넘기지 않았나
- 고친 줄이 있으면 그 앞 줄(묻는 말)과 뒤 줄(대답, 반응)도 같이 맞나

## 3. 줄마다 보는 것

1. 그 사람이 그걸 알 수 있나 (직접 봤나, 누구에게 들었나)
2. 앞 줄의 물음에 대한 대답인가 (논점을 바꿔치기하지 않았나)
3. 한 번에 읽히나 (대명사가 누구인지 거슬러 찾아야 하나)
4. 말투
5. 죽었을 수 있는 사람이 조건 없이 나오나
6. 실제 사람이 그 상황에서 그 길이로 말하나 (다친 사람이 한자 풀이를 하나)
7. 인물을 바보로 만드나
8. 주인공이 장담할 수 없는 걸 장담하나 (예측과 위험과 약속을 구별)
9. 깨달음 독백이 없던 생각을 지어내거나 방금 고른 말을 되풀이하나
10. 유명 인물이 매번 나타나 채점하나
11. 사서·연의와 맞나, 다르면 일부러 바꾼 것인가

## 4. 판정을 나눈다

- **오류**: 사실·인과·정보가 어긋난다. 반드시 고친다.
- **어색함**: 말이 되지만 부자연스럽다. 고칠지 묻는다.

## 5. 고친 뒤

- 사건 표를 다시 채워 빈칸이 없는지 본다.
- 갈래별 대본을 다시 뽑아 한 번 더 이어 읽는다.
- 같은 버릇(한자 풀이, '셈', '대답을 기다리지 않고' 등)을 전 장에서 검색한다.
