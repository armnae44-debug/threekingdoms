# 검수용 대본 · 9장 허유

현재 게임에 들어 있는 그대로 뽑았다. 9장 판정 반영본에 10장 판정 Ⅱ-3(전위·조노 장면을 9장 B 출발 장면으로 옮김)이 더해졌다.

- 읽는 법: **이름**: 대사. 이름 없는 줄은 서술이다. `〔조건: …〕`은 그 판에서만 나오는 줄이다.
- 선택지는 `▸ 선택지 이름 — 설명 (값)`으로 적었다. 줄 앞의 `#번호`는 수정 요청 때 위치를 짚는 번호다.
