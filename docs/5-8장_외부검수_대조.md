## 4. 왜 계속 놓쳤나 — 이번에 검수 방법에 더한 것

1. **고른 행동을 남이 대신 정하지 않나.** 선택 직후 세 줄 안에 주인공이 고른 것과 다른 행동을 하거나, 남이 막는 줄이 있으면 오류다. (A #137 같은 것)
2. **선택 전에 선택지 하나를 이미 정해 버리지 않나.** 선택 앞 대사가 어느 한 갈래의 행동이면 안 된다. (B #157·#163)
3. **"방법이 없었다"는 서술이 다른 갈래와 모순되지 않나.** (A #373)
4. **포로·전령·세작이 아는 범위가 시간과 맞나.** 잡힌 시점 뒤의 일을 말하면 안 된다. (B #92)
5. **공통 대사가 갈래별로 지나온 행동을 지우지 않나.** 공통 줄마다 "이 갈래에서도 이 말이 참인가"를 갈래 수만큼 확인한다. (B #365, #192, A #145)
6. **임무를 맡았으면 끝내는 과정이 있나.** (A #167)
7. **꼬아 쓴 말을 바로 쓴다.** "그 화살도 네가 지고 가는" → 책임의 내용, "어디에 두셨는지" → 거절. 다만 앞 장면이 받쳐 주는 되받기(이석의 "내 거요")는 둔다.
8. **고침안도 검수한다.** 이번에 내 고침안 셋(공병에게 이음을 넘김, 유대가 낮으면 숨김, hold에 피해 추가)이 외부에 반박당했다. 고침안이 선택을 줄이거나, 주인공을 흐리거나, 벌을 붙이지 않는지 본다.
