# 7장 관도 수정본 (검수 반영)

`7장_검수_비교.md`의 고침 목록과 2차 외부 검수(여포 대화, 받침 선택 삭제, 갈석·소칠 연결, 전위·전만 분리, 반복 조언 덜기)를 반영한 뒤 게임에서 그대로 뽑았다. A·B가 한 원고에 섞여 있고, `여포 판`/`여포 없는 판` 조건으로 갈린다. 지운 줄은 싣지 않았다.

- 읽는 법: **이름**: 대사. 이름 없는 줄은 서술이다. `〔조건: …〕`은 그 판에서만 나오는 줄이다.
- 선택지는 `▸ 선택지 이름 — 설명 (값)`으로 적었다. 줄 앞의 `#번호`는 수정 요청 때 위치를 짚는 번호다.
