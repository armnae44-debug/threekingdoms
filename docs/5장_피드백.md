# 5장 백마 피드백 (지금 원고 기준)

- 기준: 게임에 들어 있는 5장(6A/6B), 이번 반영(5장 문장 14곳) 뒤의 판.
- 범위:
  - 외부 검수가 짚은 관우 대화(A선)와 관우·여포 논쟁(B선)을 지금 판으로 다시 읽었다.
  - 5장 전체에서 같은 버릇('뜻', '그 자리', 명언처럼 맺는 말)도 검색했다.
- 판정: 오류 / 어색함 / 정리. 고침은 아직 넣지 않았다.

## 0. 외부 검수가 본 예전 판과 지금 판

외부가 문제 삼은 예전 논쟁은 지금 원고에 없다(장사치·장수, 정원·동탁을 관우가 단정, "같은 길", "답이 있는 척", "공이 남을 겁니다").

지금 판은 이렇게 바뀌어 있다.
- 정원·동탁 이야기는 여포가 **제 입으로** 한다(6B #378).
- 관우는 여포의 말을 "아까 온후는 상은 싸운 값일 뿐이라 했소. 갚고 떠나려는 나도 다를 게 없다고"(#402)처럼 **실제로 한 말대로** 되받는다.

이 둘은 외부 지적이 고쳐진 상태다. 남은 것은 아래와 같다.

## 3. 5장 전체 검색 — 문제없다고 본 것

- '그 자리'(6A #161, 6B #154·#258–261): 앞 문장이 가리키는 곳이 분명하다.
- '뜻'(6A #381·#382·#405, 6B #22·#446): 앞 대화가 무엇을 뜻하는지 받쳐 준다.
- 6A #346 "빌리는 게 아니라 뺏는 거요": 씨앗 이야기 안에서 나온 구체적인 판단이다. 명언이 아니다.
- 여포 #336, #378, #385, #389: 여포다운 말이다. 둔다.
