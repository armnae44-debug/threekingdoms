# 계획 — 2장 줄이기 (완성의 밤까지 34분 → 20분 안쪽)

> **반영됨.** 결과: 완성의 밤까지 약 34분 → 약 29분. 22분까지는 1장도 줄여야 한다.

## 0. 지금 2장에 드는 시간 (1분에 500자 기준)

| 덩어리 | 대략 | 남길까 |
|---|---|---|
| 왕삼이 맞는 장면 + 국그릇 선택 + 흙짐 열흘 | 2분 | **남김.** 왕삼을 만나는 장면 |
| 「배급 줄」(이번에 넣은 장면) | 0.5분 | 두 줄로 줄임 |
| 소칠 입대 + 창 쥐기 선택 | 1.5분 | **남김.** 소칠을 만나는 장면 |
| 「여름 · 강가」(이번에 넣은 장면) | 1분 | 두 줄로 줄임 |
| 십장 승진 + 백부장 질문 + 조노 "나리" | 2분 | **남김.** 의심 기록·조노 호칭이 여기서 정해진다 |
| **목책 기한 (선택 셋)** | 2분 | **뺌** (아래 1절) |
| 「허도로 가는 길」(이번에 넣은 장면) | 1분 | 두 줄로 줄임 |
| 왕삼 왕(王) 자 + 첫 배급 숫자 셈 | 1.5분 | **남김.** 숫자 부호 기록이 여기서 정해진다 |
| 석 달 · 묽어지는 솥 · 소칠이 쓰러짐 | 1.5분 | 남김 |
| **위림 비리 캐기** (백부장 → 비번 이틀 조사 → 창고 잠입 → 처리 넷 → 결과) | 6~7분 | **남기되 글을 줄임** (아래 2절) |
| 소칠 병 · 출정 전날 밤 | 1.5분 | 남김 |

줄이고 나면 2장은 약 15분에서 9~10분으로 준다. 완성의 밤은 약 34분에서 **약 22분**으로 앞당겨진다.

---

## 1. 목책 기한을 뺀다

- 지금 이 장면이 정하는 것: 백부장과의 관계 세 가지(이름을 적어 감 / 눈감아 줌 / 술값 빚).
- 3장 위림 이야기에는 이 셋이 없을 때 쓰는 기본 줄이 이미 있다("목책 검사 때 한 번 얼굴을 본 게 전부였다"). 그래서 빼도 이야기가 끊기지 않는다.
- 잃는 것: "말뚝 간격을 벌린 판"에서 백부장이 3장에서 "목책 일, 눈감아 준 거 잊지 말고"라고 협박하는 갈래. 이 갈래는 함께 사라진다.
- 대신 "십장이 되고 처음 받은 명령"을 한 줄로 남긴다: "십장이 되고 처음 받은 명령은 목책을 세우는 일이었다. 아홉이 사흘 동안 말뚝을 박았다."

## 2. 위림 비리 캐기는 남기고 글을 줄인다

이 덩어리는 2장에서 유일하게 "추리하고 고르는" 놀이라서 통째로 빼지 않는다. 대신
- 조사 결과(장부 베끼기·창고 지켜보기·인부 술자리)의 검은 화면 글을 각 5~6줄에서 2~3줄로 줄인다. 단서 문장은 그대로 둔다.
- 처리 넷(백부장·담판·뒷돈·보류) 뒤의 설명 줄을 줄인다.
- 「하후씨 집안」 막간(8줄)은 4줄로 줄인다.

## 3. 2장 처음에 "왜 위로 올라가야 하는지"를 준다

지금 2장은 목표가 안 보인다. 「책에 적힌 결말」 카드 바로 뒤, 2장 첫머리에 독백 두 줄을 넣는다.
```
나(독백): 건안 2년 정월, 완성. 책대로라면 그 밤까지 두 해가 채 남지 않았다.
나(독백): 졸병 하나로는 그 밤에 아무것도 못 한다. 그 전에 사람을 모으고, 위로 올라가야 했다.
```
그러면 2장의 일(왕삼과 소칠을 얻고, 십장이 되고, 위림 일로 이름을 알리는 것)이 전부 "완성을 준비하는 일"로 읽힌다. 십장이 될 때, 위림 일이 끝날 때 한 줄씩 그 목표를 다시 짚는다.
```
[십장이 되었을 때] 나(독백): 아홉. 완성의 밤에 데리고 나와야 할 사람이 아홉 생겼다.
[위림 일이 끝났을 때] 나(독백): 완성까지 한 해. 내가 할 수 있는 건 여전히 십장의 일뿐이었다.
```

## 4. 넣을 때 확인할 것
- 목책을 빼도 3장 백부장 장면의 기본 줄이 나오는지 판마다 돌려 본다.
- 의심 기록(백부장 질문), 숫자 부호(첫 배급), 조노 호칭(나리)은 그대로 정해지는지 본다.
- 다시 시간을 재서 완성의 밤이 22분 안쪽인지 본다.
