# 11·12장 최종 점검

- 범위: 11장(어젯밤의 적 / 돌아올 사람들), 12장(관도 / 여포의 군사). A·B 네 갈래, 약 2,400줄을 조건과 함께 읽었습니다.
- 줄 번호는 화면 대본의 `#번호`입니다(`11장A` = 데이터 13A, `11장B` = 13B, `12장A` = 14A, `12장B` = 14B).
- **결과: 이번에는 근거를 댈 수 있는 문제를 찾지 못했습니다.** 11·12장은 지난번 76건 점검(`11-12장_문제.md`)에서 이미 고쳐서, 그 위에 새로 걸리는 것이 없었습니다. 수를 채우려고 억지로 만들지 않았습니다.
- 그렇다고 문제가 하나도 없다는 뜻은 아닙니다. 제 눈으로 다시 읽어서 확인할 수 있는 범위에서는 찾지 못했다는 뜻입니다.
