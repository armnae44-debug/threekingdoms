# 9·10장 최종 문제 목록

- 범위: 9장(허유, A·B 두 갈래), 10장(목책 / 빈 진영, A·B 두 갈래). 모든 줄을 조건과 함께 읽었고, 의심 가는 선택지와 죽음 처리는 데이터에서 직접 확인했습니다.
- 줄 번호는 화면 대본의 `#번호`입니다(`9장A` = 데이터 10A, `9장B` = 11B, `10장A` = 12A, `10장B` = 12B).
- **결과: 확실한 문제는 3건이고, 셋 다 10장B에 있습니다.** 9장 A·B와 10장A에서는 근거를 댈 수 있는 문제를 찾지 못했습니다. 100건을 채우려고 늘리지 않았습니다.
- 고칠 안은 앞뒤 줄, 높임말, 조건과 맞춰 읽었고, 같은 말이 겹치지 않는지도 확인했습니다.

### 1. 10장B 미끼 `마오를 보낸다`: 신발 한 짝을 잃었는데 "짝짝이 신발을 신은 놈"

조건: `decoy=wounded`

| | 줄 |
|---|---|
| #230 | 마오가 흙가마니를 어깨에 메고 언덕 뒤로 갔다. 다리를 절었다. 한 짝은 제 신발, 한 짝은 남의 신발이었다. |
| #238 | 마오였다. 끌려간 자리에 **남의 신발 한 짝이 떨어져 있었다.** |
| #262 | 부장: **짝짝이 신발을 신은 놈**인데, 겁이 나서 묻는 말에 다 대답합니다. |

문제: 남의 신발은 끌려갈 때 벗겨져 우리 쪽에 남았습니다. 원소 진영에 간 마오는 제 신발 한 짝만 신고 있습니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #262 | 부장: 짝짝이 신발을 신은 놈인데, 겁이 나서 묻는 말에 다 대답합니다. | 부장: 신발 한 짝을 잃은 놈인데, 겁이 나서 묻는 말에 다 대답합니다. |

### 2. 10장B `위장은 접고 목책부터 고친다`: 옮기지 않은 군막 여덟 채가 언덕 뒤에 서 있음

조건: `dplan=pull`

| | 줄 | 조건 |
|---|---|---|
| #123 | 우리 진지 뒤 **언덕 가까이**에도 열 몇 채가 남아 있었다. | 모두 |
| #141 | 나는 **언덕 뒤에 군막을 세우지 않기로 했다.** | pull |
| #152 | 병사들이 **빈 군막 여덟 채를 언덕 뒤로 옮겼다.** … | decoy |
| #235 | 흙 가마니와 진짜 군량 가마니를 섞어 실은 수레가 언덕 뒤로 들어갔다. 군마 스무 필이 그 뒤를 따랐다. … | 모두 |
| #286 | 언덕 뒤에는 흙 가마니 수레와 말 스무 필과 **군막 여덟 채가 서 있었다.** … | 모두 |

문제: 군막 여덟 채를 언덕 뒤로 옮긴 것은 `decoy` 갈래뿐입니다. `pull` 갈래에서는 옮기지 않았고, 그 뒤 계획(#205~#215)에도 수레·말·전령만 있습니다. 빈 군막 자체는 두 갈래 모두 언덕 가까이에 있고, 뒤에서 장합군이 "군막에는 불이 켜져 있었지만"(#444·#445)이라고 보는 것도 두 갈래에 맞습니다.

고침: 두 갈래 모두에 맞게, 언덕 뒤에 있는 것과 군막을 나눠 씁니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #286 | 언덕 뒤에는 흙 가마니 수레와 말 스무 필과 군막 여덟 채가 서 있었다. 장합은 그걸 믿지 않는 것 같았다. … | 언덕 뒤에는 흙 가마니 수레와 말 스무 필이 있었고, 빈 군막마다 불이 켜져 있었다. 장합은 그걸 믿지 않는 것 같았다. … (뒤는 그대로) |

### 3. 10장B 사실대로 말하는 갈래: 조노만 갑자기 "-습니까"

조건: `truth=tell`

| | 줄 |
|---|---|
| #339 | 조노: 그때까지 버틸 수 **있겠소**? |
| #345 | 조노: 나리가 남으면 우리도 남는 거지 뭐. 그런데 나리, 부상자는 어느 길로 **뺍니까**. |
| (10장A #74) | 조노: 놓은 건 됐소. 다친 데는 없소? 이거 받으시오. |

문제: 조노는 나에게 늘 하오체를 씁니다. 바로 앞 줄(#339)도 하오체입니다. 이 줄만 합쇼체입니다.

| | 지금 | 고친 뒤 |
|---|---|---|
| #345 | …그런데 나리, 부상자는 어느 길로 뺍니까. | …그런데 나리, 부상자는 어느 길로 빼오? |

## 확인했지만 문제가 아니어서 뺀 것

| 의심한 곳 | 확인 결과 |
|---|---|
| 10장B `endure=last` 뒤에 조건 없는 줄(#480~)이 이어짐 | #478에 죽음 표시(`death`)가 있어서 그 갈래는 거기서 끝납니다. |
| 10장B 불 맡기기 `fake`에서 조노·소칠·왕삼이 죽은 갈래 | 각 선택지가 그 사람이 살아 있어야 보입니다. `none`은 셋 다 죽었을 때만 나옵니다. |
| 10장B 마구간에서 조홍이 여포를 서쪽으로 보냄 (9장B는 "문 앞을 맡긴다") | 여포 자신이 "문 옆에 서 있으란다"(#27)고 한 뒤 조홍이 다시 정하는 장면이라, 바뀐 것이 그대로 보입니다. |
| 10장B 거짓말 갈래에서 "후퇴 신호가 올랐다"가 한 번 더 나옴 (#492) | 앞의 검은 깃발은 두 번째 말뚝까지 물러나라는 신호였고, 이번 것은 문 쪽으로 빠지는 신호로 읽힙니다. |
| 9장B #104 허유가 조공에게 하게체로 말하다 "답은 갔소?" | 같은 자리에 있는 여포에게 하오체로 던진 말로 읽힙니다(#13에서도 여포에게 하오체). |
| 9장A #208과 #216·#217에서 저수가 내 이야기를 캐묻는다는 말이 두 번 나옴 | 허유에게 들은 말을 장면 끝에서 정리하는 줄입니다. |
| 10장A #217 "순유께" (다른 곳은 "순유 공께") | 부하에게 하는 말이라 줄여 부른 것으로, 틀렸다고 하기 어렵습니다. |
| 10장A #3 떠나기 전 전위가 내 어깨에 손을 얹음 | 9장A에는 전위가 오소에 따라가는지 남는지 정한 줄이 없어서 부딪치지 않습니다. |
| 9장·10장의 조건 없는 왕삼·조노·소칠 이름 줄 | 죽은 사람 이름은 엔진이 "방패병 고참"·"노병"·"어린 병사"로 바꿔 보여 줍니다. |
