# 기획 — 쉬는 구간과 인연 줄기

> 목적: 큰 분기를 새로 만들지 않고, **"내가 고른 게 나중에 장면으로 돌아온다"**는 체감을 게임 전체에 까는 것.
> 판단 기준(장마다 하나 이상): ① 예전 선택이 **장면으로** 돌아오는 정산 ② 대가가 걸린 판단·추리 ③ 이름 있는 사람의 운명이 걸린 순간.

---

## 0. 한눈에 보기

```
1장 ─ 2장 ─ 3장 ─[심문]─ ①쉬는 구간 ─ 4장 ─ ②쉬는 구간 ─ 5장[고향] ─ 6장 ─ ③쉬는 구간 ─ 7장 ─ 8장[물을 붓자] ─ ④마지막 밤 ─ 9장 ─ 10장[정산1] ─ 11장[정산2] ─ 12장[정산3] ─ 에필로그[가지 않은 길]
```

| 종류 | 무엇 | 개수 |
|---|---|---|
| 본편 고정 장면 (누구나 봄) | 3장 심문, 5장 고향, 8장 물을 붓자 | 3 |
| 쉬는 구간 (골라서 봄) | ①②에서 각 2개, ③④에서 각 1개 = 한 판에 6번 | 보기 15개 |
| 정산 장면 (고른 것·안 고른 것이 돌아옴) | 8장, 10장 목책의 밤, 11장 만총, 12장 "자네는 누군가", 에필로그 | 5곳 |

**원칙 세 가지**
1. 재미의 바닥은 본편 고정 장면이 책임진다. 방문을 하나도 안 골라도 장마다 정산과 판단이 있다.
2. 안 고른 보기도 비지 않는다. **방치한 대가 장면**이 따로 나온다.
3. 보기는 메뉴 이름이 아니라 **"찾아오는 일"**로 보여 준다.

## 1. 본편 고정 장면 (새로 넣는 것 3개)

### 1-1. 3장 끝 · 심문 「말은 언제 매어 두었나」
**조건:** 완성에서 장수 쪽 군마 두 필을 끌어냈을 때 (`horseStolen`). 조앙이 살았으면 조앙도 그 자리에 있다.

**흐름**
1. **전날 밤, 백부장이 찾아온다.** 습격 전에 주인공의 보고를 "못 들은 걸로 하지"라며 묵살한 그 백부장이다.
   - "내 앞에서 그런 말을 한 적 없는 거다."
   - **덮어 준다**: 백부장이 빚을 진다(나중에 12장 증언). 대신 심문에서 "보고했다"는 방패를 못 쓴다.
   - **거절한다**: 백부장은 심문에서 잡아뗀다. 그날 곁에 있던 조노가 증인이 될 수 있다(조노 생존 시).
2. **심문.** 조조의 막사, 막료가 묻는다. 의심은 "알았으면 왜 위에 알리지 않았나", 더 나쁘게는 "장수 쪽과 내통한 것 아닌가".
3. **증거 내밀기 (추리).** 3장에서 **실제로 본 것만** 카드로 나온다. 카드 3장 이상을 맞게 내밀면 통과.
   - 성루 병사들이 창 쥔 손을 풀지 않음 / 갑옷 실은 수레 통과 요청 / 숙모 일 뒤 장수가 안 보임 / 호거아가 전위의 잔만 셈 / 장수 군마가 밤에도 안장을 얹고 있음 / 극을 숨긴 장작더미
   - 상관없는 카드(예: "연회 술이 싱거웠다")를 내면 의심이 커진다.
4. **결과**
   - **통과**: "눈이 좋은 자로군." 묵살한 백부장이 벌을 받는다(2장부터 이어진 백부장 이야기의 끝). 조앙이 주인공을 처음으로 "쓸 만한 사람"으로 본다. → **조앙 줄기 열림**
   - **실패**: 말 두 필은 절도로 처리, 곤장. 조앙이 살아 있으면 "그 말이 없었으면 저는 여기 없습니다" 하고 막아 준다. 의심은 장부에 남는다 → **11장 만총 조사가 더 일찍, 더 세게 온다.**

### 1-2. 5장 행군 중 · 고향 「강 건너에서 온 노파」
**조사 결과:** 진짜 조평의 고향은 "연주 동군 강가 마을"(11장 만총 조사에 이미 나오는 설정). **백마가 바로 동군**이다. 백마로 가는 길이 이 몸의 고향 근처를 지난다.

**흐름:** 원소군이 강을 건넌다는 소식에 피란민이 몰려온다. 그중 한 노파가 "평아, 조평이를 아시오" 하고 군사마다 붙잡고 묻는다. → 아래 [5. 시험 장면 초안] 참고.

**선택 (장면 안)**
- **아들로서 다가간다**: 어머니가 아들을 끌어안는다. 그런데 손을 보고 멈춘다. (→ 어머니 줄기 열림, 정산 11·12장)
- **군후로서 피란길만 열어 준다**: 이름을 밝히지 않고 피란민을 남쪽으로 보낸다. 노파는 끝내 아들을 못 찾고 간다.
- **외면한다**: 행군을 멈출 수 없다. (→ 에필로그 "가지 않은 길"에 남는다)

### 1-3. 8장 땅굴 · 「물을 붓자」
**흐름:** 원소군 땅굴이 다가온다. 역사대로라면 긴 도랑을 판다. 주인공은 1장 복양 도랑과 4장 하비 물길에서 익힌 눈이 있다.

**추리:** 진지 주변 우물 세 곳의 물 높이와 흙 감촉(모래층 여부)을 보고 **굴이 지나갈 자리**를 짚는다. 하비 물길 퍼즐의 짧은 판.
- **맞히면**: 물을 끌어 굴을 통째로 무너뜨린다. 이름이 위로 올라가고, 저수의 명단에 굵게 오른다.
- **틀리면**: 엉뚱한 곳에 물을 대서 우리 목책 밑이 꺼진다. 그 구간 병사가 묻힌다(이름 있는 부하일 수 있음).
- **②에서 진기나 장오·이석을 데려왔으면** 단서가 하나씩 더 나온다(진기: 땅속 소리 / 장오·이석: 흙 감촉).

## 4. 정산 장면 정리

| 어디 | 무엇이 걸리나 |
|---|---|
| **8장 물을 붓자** | ② 새 인재 / 추리 결과 |
| **10장 목책의 밤 (A선) · 고람의 언덕 (B선)** | ③ 조앙 측근 여부(주인공 위치) / ④ 마지막 밤의 그 사람 / 부하 줄기들 / 방치 대가 |
| **11장 만총 조사** | 심문 결과(장부의 의심) / 어머니 줄기(편지·증언) |
| **12장 "자네는 누군가"** | 조앙 / 조노 / 백부장(빚) / 어머니 — **이 넷 중 몇 명이 주인공 편에 서느냐로 추방·감시·신임이 갈림** |
| **에필로그** | 끝낸 줄기의 결말 한 장면씩 + **"가지 않은 길"**: 만나지 않은 인연을 이름만 흐리게 ("조평의 어머니 — 만나지 않음", "진기 — 다른 부대에서") |

## 5. 시험 장면 초안 — 5장 「강 건너에서 온 노파」
> 판단용 초안. 말투 규칙(주인공→부하 반말, 조노 하오체) 적용.

```
행군이 멈췄다. 앞쪽 길이 사람으로 막혀 있었다.

강 건너에서 온 피란민들이었다. 등에 솥을 진 사내, 아이를 업은 여자, 소 한 마리를 끄는 노인. 원소의 군사가 강을 건넌다는 말이 그들보다 하루 먼저 와 있었다.

조노: 길을 비키라고 할까요, 나리.

나는 대답하지 않았다. 피란민 사이로 노파 하나가 군사들 소매를 차례로 붙잡고 있었다.

노파: 평아… 조평이를 아시오. 연주 군사로 끌려갔소. 키는 이만하고, 왼쪽 눈썹에 흉이 있소.

노파의 손이 내 앞 병사의 소매를 놓고, 내 소매를 잡았다.

나는 그 손을 내려다봤다. 마디가 굵고 손톱 밑이 시커먼 손이었다. 복양 도랑에서 처음 내려다본, 이 몸의 손과 같은 손이었다.

노파가 고개를 들었다. 눈이 내 얼굴에서 멈췄다. 왼쪽 눈썹으로 갔다가, 다시 내 눈으로 왔다.

노파: …평아?

조노가 내 뒤에서 숨을 멈췄다. 이 몸의 이름이 조평이라는 걸 아는 사람은 많았다. 이 몸의 어머니를 아는 사람은, 여기서 아무도 없었다.
```

**선택**
- "…어머니." — 아들로서 다가간다
- "군후 조평이오. 남쪽으로 가는 길을 열어 드리겠소." — 이름만 대고 피란길을 연다
- 소매를 빼고 행군을 재촉한다

**"어머니"를 골랐을 때 이어지는 줄 (초안)**
```
노파가 나를 끌어안았다. 흙냄새와 연기 냄새가 났다. 한참 뒤 노파가 내 손을 잡아 제 얼굴로 가져갔다. 손바닥을 쓸어 보다가, 손가락 마디에서 멈췄다.

노파: 붓을 쥐었구나. 우리 평이가.

노파는 더 묻지 않았다. 묻지 않는 얼굴이 아니라, 묻지 않기로 한 얼굴이었다.
```
→ 어머니는 눈치챘지만 묻지 않는다. 이 한 줄이 11장 만총 조사에서 "제 아들 맞습니다"로 돌아온다.

## 6. 분량과 만드는 순서

| 항목 | 개수 | 줄 수(대략) |
|---|---|---|
| 본편 고정 장면 | 3 | 각 80~150줄 |
| 쉬는 구간 보기 | 15 | 각 10~30줄 |
| 방치 대가 장면 | 6 | 각 10~30줄 |
| 정산 장면 수정 | 5곳 | 갈래당 10~40줄 |

→ 새로 쓸 분량은 지금 장 두 개 정도.

**만드는 순서 (시범부터)**
1. **시범:** 3장 심문 + ① 조앙 방문 + ③ 측근 제안 + 10장·12장 정산까지 **조앙 줄기 하나만** 끝까지 넣는다. 직접 플레이해서 판단.
2. 괜찮으면: 5장 고향과 어머니 줄기, 8장 물을 붓자.
3. 부하 셋 줄기와 방치 대가.
4. 마지막: 에필로그 "가지 않은 길".
