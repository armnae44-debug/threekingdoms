# 원고 작업 규칙 (이 폴더)

- 원고(`N장_*.md`)를 고치거나 새로 쓴 뒤에는 커밋 전에 반드시 문장 검사기를 돌린다.
  - `python3 tools/문장검사.py N장_*.md`
  - 걸린 줄은 하나씩 고친다. 고치지 않고 두는 줄은 왜 괜찮은지 말할 수 있어야 한다(의성어 "딱." 같은 것).
- 검사기가 잡는 것: 반응 박자로 쓰는 "누가 나를 봤다", "A가 아니라 B" 대구, "~해 주었다" 반복, 동작 명사화("~것이 보였다", "들어 보였다"), "~다고 했다" 연달아, 대답 못 함·목소리 갈라짐 반복, "튕겨 나옴", 흐린 타격("무언가에 맞아"), 금지어(시선, 머물, 무거웠다, 공기, 한참, 천천히, 한동안, ……), 서술자가 장면 끝에 붙이는 정리문, 짧은 조각 문단("왔다." "오소."), 기능으로 사람 바꿔 쓰기("그 귀였다"), 주인공이 알 수 없는 남의 속 단정("알아채지 못했다"), 뜻보다 앞서는 비유, 시대·천재 단정, 흐린 동작("극을 거꾸로 세웠다").
- 명령 대사는 할 일만 말한다. 이유 설명을 붙이지 않는다.
- 인물이 플레이어의 선택을 평가하지 않는다.
- 검토자 예시 문장은 그대로 옮기지 않는다. 방향만 받고 새로 쓴다.
- 갈래를 확인할 때는 `tools/route.py`로 읽기본을 만들어 처음부터 끝까지 읽는다.
