- 만총이 흉 자리 기록을 다시 펴 확인하는 동작으로 바꾼다.

- 만총이 한 번 묻고("공자 쪽인가") 답을 들은 뒤 선을 긋는다.

- "하나만이라면 주워 배웠다 하겠지. 그런데 재는 법, 셈법, 병기까지 다르군."

- 상인이 "돈을 쌌던 주머니는 아직 있습니다"라고 하고, 만총이 물건을 대조한다.

- **12장에 영향**: 12장 조조 대사("그 돈주머니에 내 군막 표식이 찍혀 있었다지", 1481줄)를 "그 주머니가 내 군막에서 나간 것이더군"으로 맞춘다.

- 청년이 들고 온 문서의 숫자를 바로잡는 걸 만총이 먼저 본다.

- "제가 배운 셈법에는 없습니다. 쓰는 사람이 또 있는지부터 알아봐야겠습니다."

- 숫자 2개 이상일 때만 청년의 이름이 나온다. 0~1개면 검산 보고로 짧게 끝난다.

- 묶음 1의 41번과 같이 고친다.
