# 계획 — 선택지를 요약으로, 상태 칸 고치기

> **반영됨.** 대사가 두 번 나오는 곳은 A·B 전체 판과 1~4장 판에서 0곳이었다.

---

## 1. 상태 칸

### 점 네 개는 무엇인가
점 네 개는 그 사람이 나를 얼마나 믿는지를 보여 준다. 휘하 창에 이미 있던 네 단계를 점으로 옮긴 것이다.

| 켜진 점 | 뜻 |
|---|---|
| 1 | 모른다 |
| 2 | 지켜본다 |
| 3 | 믿는다 |
| 4 | 목숨을 건다 |

신뢰가 아주 나빠진 사람은 점이 빨갛게 바뀐다(등을 돌렸다). 왕삼은 점 셋이 켜져 있었으니 "믿는다" 단계다.

점만으로는 무슨 뜻인지 알 수 없었다. 그래서 이름 옆에 그 단계를 글자로 적는다. 예: `왕삼 · 믿는다`.

### 본문을 가리는 문제
지금은 상태 칸이 본문 칸 위쪽을 차지한다. 그래서 본문이 그 밑으로 밀리고, 위로 올라간 글이 칸 아래에서 흐려져서 가려진 것처럼 보인다.

- **노트북:** 상태 칸을 오른쪽 본문 칸에서 빼서 왼쪽 그림 칸의 왼쪽 위에 얹는다. 반투명한 바탕에 작게 둔다. 본문 칸은 원래대로 비워 둔다.
- **휴대폰:** 이름과 점만 한 줄로 둔다. 「조공의 시선」 설명 글은 숨기고, 눈금을 누르면 그때 보여 준다.
- 「조공의 시선」 설명 글은 한 줄로 줄인다.
  - 1~3칸: "가끔 눈이 머문다. 넷째 칸부터 내 청이 통한다."
  - 4칸: "내 이름을 기억한다. 한 칸 더 차면 뒷조사를 받는다."
  - 5칸 이상: "내 뒤를 캐게 했다."

### 수묵 톤 시험
지금 그림을 그대로 쓴다. 시험으로 넣은 수묵 톤 코드는 지운다.

## 2. 선택지를 요약으로 바꾼다

### 지금 문제
대사 한 줄이 통째로 선택지에 들어간 곳이 169곳이다. 그중 약 3분의 2는 고른 뒤에 같은 대사가 한 번 더 나온다. 그래서 같은 말을 두 번 읽는다.

### 바꾸는 방법
- 선택지에는 **무엇을 하는지만** 짧게 적는다(~한다, ~라고 한다, ~냐고 묻는다).
- 고르면 원래 대사를 주인공이 말한다.
  - 지금도 고른 뒤에 대사가 나오는 곳은 그대로 둔다.
  - 고른 뒤에 대사가 없던 곳은, 원래 선택지에 있던 대사를 주인공이 먼저 말하게 한다.
- 선택지 밑의 작은 설명 줄은 남긴다. 다만 요약과 같은 말이면 지운다.

### 요약 목록

### 설명 줄을 지우는 곳
요약과 설명 줄이 같은 말이 되는 곳은 설명 줄을 지운다.
- "서쪽 논에서 발이 빠진 일부터 말한다" 밑의 "공을 줄인다"는 남긴다(뜻이 다르다).
- "장합과 고람이 온다고 이름까지 알린다" 밑의 "이름까지 말한다"는 지운다.
- "후성 한 사람에게만 보내자고 한다" 밑의 "불호령을 맞은 자다"는 남긴다.

### 넣은 뒤 확인할 것
- 고른 뒤 대사가 두 번 나오지 않는지, 한 번도 안 나오는 곳이 없는지 169곳을 모두 돌려 본다.
- 갈래 기록(어느 선택을 했는지)은 바뀌지 않는다. 화면에 보이는 글자만 바뀐다.
