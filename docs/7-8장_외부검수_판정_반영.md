# 7·8장 외부검수 판정과 반영

유형 표기 (5~8장 피드백에서 반복된 병):
- **①이동**: 사건을 위해 인물을 옮김
- **②대가**: 원인 없는 벌·비용
- **③정보**: 인물이 알 수 없는 걸 말함/봄
- **④선택**: 고른 것보다 나쁜 행동이 결과에 나옴
- **⑤해설**: 인물이 자기·남을 해설
- **⑥둔화**: 주인공을 띄우려 주변을 둔하게
- **문장**: 표현·연결
