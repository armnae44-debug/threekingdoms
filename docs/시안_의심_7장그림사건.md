# 시안 — 7장 그림 사건과 "조사는 무조건 일어난다"

> 게임에 들어갈 대사 그대로 썼다. 아직 반영 전이다.
> 표기: 「선택지」 / 부제는 `—` 뒤. 대사 앞 이름이 없는 줄은 서술이다.

---

# 0. 뼈대: 의심은 피할 수 없다. 고르는 건 "어떤 의심이냐"

```
4장 하비에서 군후가 된다
   └─ 막간 「새 군후의 내력」: 만총이 절차대로 연주에 사람을 보낸다   ← 누구나 본다
         (원래 조평의 어머니: "제 아들은 이름자도 못 그렸습니다")
7장 그림 사건 ── 능력을 쓴다 → 유엽이 "선생"이라 부른다 (은사의 제자)
             └─ 숨긴다   → 병사가 다친다 / 축 자리를 바로잡다 들킨다 (방사)
             └─ 출처 넷 → 그림 / 서역 상인 / 꿈 / 말 못 함 → 각각 뒤에서 터진다
11장 만총 막간: 모인 진술을 맞대어 한 단어를 쓴다 (간자·은사·방사·명문)
12장 조조 심문: 그 단어로 시작한다 → 결말 넷
```

**의심이 낮은 판도 비지 않는다.** 증거가 거의 없으면 만총은 "몰락한 명문가의 숨은 아들"로 결론을 낸다. 조조가 그 집안 이름을 쓰라고 한다. 다 숨겨서 정체를 지켰는데, 결국 이름을 하나 더 잃는다.

---

# 1. 새 막간 (4장 끝) 「새 군후의 내력」 — 누구나 본다

```
허도, 현령의 관아. 밤.

만총이 하비에서 올라온 공적 명부를 넘겼다. 새로 군후가 된 이름이 열 남짓이었다.
만총: 하나씩 연주에 사람을 보내라. 고향, 집안, 함께 징집된 자.
아전: 군후 하나하나를 다 말입니까?
만총: 주공께서 이름을 기억하기 시작한 자들이다. 내가 먼저 알아 둬야 한다.

아전이 명부를 받아 갔다. 만총은 마지막 장을 덮다가 한 이름에서 손을 멈췄다.
조평. 연주 징집 보병. 흥평 원년 복양.
만총: …복양에서 살아 돌아온 졸이 이 년 만에 군후라.
그는 그 이름 옆에 작은 점을 찍었다. 다른 이름들 옆에는 찍지 않은 점이었다.
```

석 달 뒤 (5장 백마 직전 막간, 짧게):

```
아전: 연주 동군, 강가 마을. 조평의 어머니를 찾았습니다.
아전: 아들이 십장이 됐다 하니 웃었습니다. 그 애는 제 이름자도 못 그렸다고.
만총: 지금 그 자는 장부를 맡고 있다.
아전: …예.
만총은 대답하지 않았다. 점 옆에 한 줄을 적었다. 글을 모르는 자가 글을 안다.
```

→ 이 두 장면은 **모든 판에 나온다.** 플레이어는 5장에 들어가기 전에 이미 "누군가 나를 캐고 있다"를 안다.

# 2. 7장 그림 사건 (대본)

지금 게임에서 바뀌는 곳은 **"그런 것이 움직이는 모습을 본 적이 있습니다" 실언 이후**부터다.

## 2-1. 출처 (선택지 둘 → 넷)

```
유엽: 어디에서 보았소? 만든 사람을 부를 수 있다면 좋겠는데.

장인들이 쓰는 톱 소리가 크게 들렸다.
나(독백): 영화라고 할 수는 없었다. 어느 고을이라고 둘러대면, 그 고을에 사람이 간다.

「"오래전에 본 그림입니다."」 — 흔한 거짓말이다
「"서역 상인이 들고 온 그림이었습니다."」 — 아무도 확인 못 할 먼 곳을 댄다
「"…꿈에서 봤습니다."」 — 거짓말은 아니다. 다 말하지도 않는다
「"어디서 보았는지는 말씀드릴 수 없습니다."」 — 꾸며내지 않는다
```

**고른 대사:**

```
[그림]
나: 직접 본 것은 아닙니다. 오래전에 본 그림입니다.
유엽: 그림이라.

[서역]
나: 몇 해 전, 서역 상인이 비단과 함께 그림 몇 장을 팔러 왔습니다. 그중에 이런 병기가 있었습니다.
유엽: 서역.
그의 눈이 처음으로 빛났다.
유엽: 대진(大秦)의 그림이었소? 그 나라에는 성을 치는 병기가 우리와 다르다 들었소.
나(독백): 대진. 로마였다. 거짓말 위에 거짓말이 하나 더 얹혔다.

[꿈]
나: …꿈에서 봤습니다.
옆에서 줄을 감던 장인의 손이 멈췄다.
유엽은 웃지 않았다. 그게 더 무서웠다.
유엽: 꿈이라.

[말 못 함]
나: 어디서 보았는지는 말씀드릴 수 없습니다.
유엽이 그림에서 눈을 들었다.
```

## 2-2. 유엽의 시험 「다시 그려 보시오」 (넷 다 여기로 온다)

```
유엽이 판 하나를 내 앞에 내려놓았다. 숯 조각도 함께였다.
유엽: 본 것이 있다면, 기억나는 대로 다시 그려 보시오. 장인들에게 보여 주겠소.

나(독백): 손이 판 위에서 멈췄다.
나(독백): 나는 그리는 법을 안다. 옆에서 본 모습, 축의 자리, 팔 길이의 비. 학교에서, 화면에서, 수없이 본 그림법이다.
나(독백): 그런데 이 시대 사람은 병기를 그렇게 그리지 않는다.

「아는 대로 그린다」 — 병기가 빨라진다. 그림이 나를 말해 버린다
「이 시대 사람처럼 그린다」 — 아무도 의심하지 않는다. 병기가 늦어진다
```

### 아는 대로 그린다

```
숯이 판 위를 지나갔다. 받침, 축, 긴 팔, 짧은 팔, 추를 담는 상자.
멀리 있는 다리는 짧게 그렸다. 팔 끝에는 길이를 적었다. 손이 저절로 그렇게 했다.

다 그리고 나서야 판을 내려다봤다. 장인 둘이 어깨 너머로 들여다보고 있었다.
아무도 말하지 않았다.

유엽이 판을 들어 올렸다. 한참 돌려 보았다. 앞으로, 옆으로, 거꾸로.
유엽: 이건 그림이 아니오.
나: …예?
유엽: 우리는 병기를 그릴 때 위에서 본 모양과 옆에서 본 모양을 따로 그리오. 장인은 두 장을 맞춰 보며 머릿속에서 세우지.
유엽: 그대는 한 장에 다 그렸소. 멀리 있는 다리를 짧게 그려서, 보는 사람이 깊이를 알게 했고.
그가 팔 끝에 적힌 숫자를 손톱으로 짚었다.
유엽: 그리고 이건 그림이 아니라 셈이오.

장인 하나가 판을 받아 들더니, 말없이 자기 무릎 위에 놓고 들여다보기 시작했다.

유엽: 그대는 이런 그림을 본 사람이 아니오.
유엽: 이런 그림을 그리는 법을 배운 사람이지.
```

출처별로 한 줄이 붙는다.

```
[그림]   유엽: 본 그림을 옮겨 그렸다는 사람이, 그 그림에 없던 숫자까지 적는군.
[서역]   유엽: 대진의 그림법이 이렇다면, 나는 대진에 가 봐야겠소. …농이오.
         그는 웃지 않았다. 그날 저녁 유엽이 허도로 편지를 보냈다는 말을 들었다.
[꿈]     장인 하나가 슬그머니 가슴께를 더듬었다. 부적을 품고 있는 자리였다.
[말 못 함] 유엽: 말할 수 없는 곳에서, 이런 것을 배웠다.
         그가 판을 조홍에게 가져가겠다고 했다. 말리지 못했다.
```

**결과:**
- 투석기가 **사흘 빨리** 완성된다. 첫 망루가 무너지는 날이 앞당겨지고, 그 사이 덮개 밖에서 다칠 병사 둘이 다치지 않는다.
- 그날부터 유엽이 주인공을 **"선생"**이라 부른다. 은사의 제자 +2.

```
(사흘 뒤, 작업장)
유엽: 선생. 축 받침은 이 두께면 되겠소?
조홍이 지나가다 걸음을 멈췄다. 유엽이 부른 호칭을 들은 얼굴이었다.
조홍: …선생?
조홍은 그 말만 하고 지나갔다. 그 뒤로 조홍은 나를 이름으로만 불렀다.
```

### 이 시대 사람처럼 그린다

```
위에서 본 모양만 그렸다. 축은 대충 가운데쯤. 팔 길이는 적지 않았다.
일부러 선 하나를 비뚤게 그었다. 숯을 쥔 손이 오히려 더 떨렸다.

유엽이 판을 받아 보더니 고개를 끄덕였다.
유엽: 그림은 그림이군. 그린 사람이 병기를 만들어 본 자는 아니었던 모양이오.
나는 숨을 내쉬었다. 들키지 않았다.
```

**결과 1 — 사흘이 늦어진다.**

```
(모형이 세 번째로 부서진 날)
장인이 부서진 축을 들고 와서 판 위의 그림과 번갈아 봤다.
장인: 군후, 이 그림대로는 축이 버티질 못합니다. 어디에 걸어야 하는지 그림에 없습니다.
나(독백): 안다. 반 자 뒤다. 말하면 끝난다.

그날 오후, 물을 길으러 덮개 밖으로 나간 우리 병사 둘이 화살을 맞았다.
하나는 어깨였고, 하나는 돌아오지 못했다.
그 망루는 원래대로라면 그날 아침 무너져 있었어야 했다.
```

명부(12장)에 이 이름이 오르고, 비고란에 한 줄이 적힌다.

```
갈석. 물을 길으러 나갔다. — 그날 아침 무너졌어야 할 망루.
```

**결과 2 — 열흘 뒤, 들킨다.**

```
실물 병기가 세워진 날. 장인들이 추를 매달고 축에 쐐기를 박고 있었다.
나는 뒤에서 보고 있었다. 축이 너무 앞에 있었다. 저대로면 팔이 돌다 틀을 친다.

「그냥 둔다」 — 시험이 한 번 더 실패한다
「무심코 말한다」 — 손이 먼저 움직였다
```

```
[무심코 말한다]
나: 그 축, 반 자만 뒤로.
장인이 돌아봤다. 그리고 유엽도.
장인이 쐐기를 빼 반 자 뒤로 옮겼다. 그날 돌은 처음으로 유엽이 표시한 곳까지 날아갔다.

저녁에 유엽이 내 그림 판을 들고 왔다. 처음 그렸던, 일부러 비뚤게 그린 그 판이었다.
유엽: 그림은 그렇게 서툴렀는데.
유엽: 고칠 자리는 반 자까지 정확히 아는군.
그는 판을 내려놓고 갔다. 더 묻지 않았다. 묻지 않는 게 더 무서웠다.
```
→ 방사 +1, **숨긴 횟수 +1**. 곽가의 눈(세 번 숨기면 들킴)으로 이어진다.

```
[그냥 둔다]
팔이 돌다 틀을 쳤다. 장인 하나가 튄 나무 조각에 이마가 찢어졌다.
나는 아무 말도 하지 않았다. 그날 밤 장인들이 축을 앞뒤로 옮겨 보며 밤을 샜다.
닷새 뒤에야 그들이 직접 반 자 뒤를 찾아냈다.
```
→ 의심 0. 대신 투석기가 닷새 더 늦어진다. 그 사이 망루 사격으로 부상자가 더 생기고, 명부 비고에 이름이 하나 더 오른다.

## 2-3. 출처가 뒤에서 터진다

### 그림 → 12장 조조

```
조조: 관도에서 그 병기, 그림을 보고 그렸다지.
조조: 그 그림, 지금이라도 가져와 보게.
「잃어버렸습니다」 / 「태웠습니다」 / 「…그림은 없었습니다」
```

### 서역 상인 → 11장 반전

```
(11장, 만총 막간)
아전: 유엽 공이 허도에 부탁한 일이 있었습니다. 서역 상인 중 병기 그림을 판 자를 찾아 달라고.
만총: 찾았나.
아전: 찾았습니다. 안식(安息)에서 왔다는 상인 하나가, 몇 해 전 연주에서 그런 그림을 팔았다고 했습니다.
만총: …그래?
만총은 그 진술을 오래 보았다. 거짓말이 맞아떨어졌다. 맞아떨어진 거짓말이 제일 수상했다.
만총: 그 상인을 다시 불러라. 이번엔 내가 묻는다.

(며칠 뒤)
아전: 상인이 털어놓았습니다. 누가 돈을 주며, 누가 묻거든 그렇게 말하라 했답니다.
만총: 누가.
아전: 관도에서 온 사람이라 했습니다. 이름은 몰랐고, 웃는 얼굴이었다고.
```

```
(12장, 조조의 군막)
곽가: 그 상인에게 돈을 준 건 나요.
나: …왜.
곽가: 그대가 서역을 댔다는 말을 듣고, 서역 상인이 하나 나타나면 누가 제일 먼저 안도할지 보고 싶었지.
곽가: 그대 얼굴은 못 봤소. 대신 그대가 그 소식을 듣던 날 밤, 술을 한 잔 더 마셨다는 건 들었소.
```
→ 서역 갈래가 끝까지 살아남으면, **곽가가 판 함정에 빠졌는지**가 12장에서 드러난다. 7장 이후 "서역 상인이 확인해 줬다"는 소식을 들을 때 "안도한다 / 의심한다" 선택이 들어간다.

### 꿈 → 장인들이 말을 아낀다, 조조가 꿈을 묻는다

```
(8장, 땅굴)
공병 하나가 내 쪽을 보고 동료에게 속삭였다. 꿈에서 병기를 본다는 군후가 저 사람이라고.
(12장)
조조: 오늘 밤에는 무슨 꿈을 꿀 텐가.
「주공의 꿈은 꾸지 않습니다」 / 「…꿔도 말씀드리지 않겠습니다」 / 「원소가 강을 건너는 꿈을 꿨습니다」
```

### 말 못 함 → 조홍이 사람을 붙인다

```
(8장 첫머리)
낯선 병사 하나가 우리 부대로 왔다. 조홍 장군이 보냈다고 했다. 이름은 구양.
구양은 창을 잘 썼고, 밤마다 내 천막 근처에서 오래 서성였다.
(며칠 뒤)
돌아오니 짐이 조금 흐트러져 있었다. 셈판이 엎어져 있었다.
[셈판에 꼬부랑 부호가 있으면] 그 위에 젖은 손가락 자국 하나.
```
→ 10장 목책의 밤에 구양이 같은 목책에서 함께 싸운다. 감시하러 온 사람이 같이 피를 흘린다. 살아남으면 11장에 조홍에게 보고하러 가서 이렇게 말한다.

```
구양: 원소에게 보낸 것은 없었습니다. …목책에서 끝까지 서 있었습니다.
```

# 3. 11장 만총 막간 「동그라미」 (사마의 대사 바로잡음)

```
만총이 관도에서 온 장부를 펼쳤다. 여백 곳곳에 처음 보는 부호가 적혀 있었다.
만총: 하북의 암호인가.
아전: 세작들이 쓰는 부호는 이렇게 생기지 않았습니다.

형의 심부름으로 와 있던 청년이 등잔을 당겨 장부를 들여다봤다. 한참 말이 없었다.
청년: 글자가 아닙니다. 숫자입니다.
만총: 숫자?
청년: 생긴 것이 열 가지뿐입니다. 산가지 셈과 이치는 같습니다. 자리가 하나 옮겨 가면 값이 열 배가 되지요.
청년: 다른 건 둘입니다. 산가지를 늘어놓지 않고 붓으로 바로 씁니다. 그리고—
그가 손가락으로 작은 동그라미 하나를 짚었다.
청년: 빈자리마다 이걸 칩니다. 산가지는 빈자리를 그냥 비워 두니, 셈하다 한 칸 밀리면 백이 천이 됩니다. 이 동그라미 하나 때문에 그런 일이 없습니다.
청년: 이걸 만든 사람은 셈을 배운 사람이 아닙니다. 셈을 새로 만든 사람입니다.

만총: …자네 이름이 뭐였더라.
청년: 하내 사마씨, 둘째입니다.
```

(부호를 한 번도 안 썼으면 이 장면은 없고, 만총 막간은 다른 진술로만 간다.)

# 4. 플레이 방식별로 겪는 이야기

| 플레이 | 7장에서 | 11장 만총이 쓰는 단어 | 12장 |
|---|---|---|---|
| **다 쓴다** (아는 대로 그림, 부호, 거리를 먼저 댐) | "선생" 호칭, 조홍의 경계 | **은사** 또는 **방사** | "스승을 데려오라" 또는 "내 끝도 읽었겠군" |
| **섞어 쓴다** (서역 상인 + 아는 대로) | 유엽의 편지, 상인의 확인 | 갈림 | 곽가의 함정이 드러난다 |
| **다 숨긴다** (서툴게, 산가지, 모른 척) | 갈석이 죽는다, 축 자리에서 들킬 뻔 | 숨긴 횟수 3 이상이면 곽가가 **방사**를 민다. 아니면 **명문** | 남의 집안 이름을 받는다 |
| **말을 안 한다** (말 못 함) | 구양이 붙는다 | **간자** | 칼이 탁자에 놓인다. 저수·조노·구양이 살릴 수 있다 |

# 5. 필요한 작업 (7장 시범분)

| 무엇 | 분량 |
|---|---|
| 4장 끝·5장 앞 만총 막간 2개 | 약 20줄 |
| 7장 출처 넷 + 다시 그리기 + 결과 | 약 110줄 |
| 7장 "축 반 자" 장면 + 갈석 | 약 25줄 |
| 출처별 뒷장 회수 (8장 구양, 11장 상인, 12장 질문) | 약 45줄 |
| 플래그 | 출처, 그림 방식, 숨긴 횟수, 가설 점수 넷 |

**갈석**은 새로 만드는 병사다. 7장 첫머리(물 긷기, 덮개 밑 밥)에 두 번 얼굴을 비추고 나서 죽어야 무겁다. (10장의 석두와 겹치지 않게 이름을 따로 정했다.)
