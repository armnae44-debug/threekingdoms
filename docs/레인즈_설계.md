# 관도 회귀 — 설계 (가제)

레인즈 방식(카드 좌/우, 네 게이지 줄타기)으로 만드는 삼국지 관도 게임. 한 판 5~10분, 전체 약 1시간.

## 1. 한 줄 개요

조조 진영의 말단 군관인 나는 죽을 때마다 관도 첫날로 돌아온다. 네 게이지가 어느 쪽 끝에 닿아도 죽는다. 오소 기습의 밤까지 살아남으면 이긴다.

## 2. 한 판의 흐름

1. 카드가 한 장 나온다. 인물 그림, 두세 줄의 말, 그리고 좌/우 선택이 있다.
2. 카드를 왼쪽이나 오른쪽으로 민다. 선택은 "한다 / 안 한다" 같은 짧은 말이다.
3. 게이지가 움직이고 날짜가 간다(카드 한 장이 하루).
4. 정해진 날짜에는 이정표 사건(백마, 토산, 오소…)이 끼어든다.
5. 어느 게이지든 0이나 100에 닿으면 죽음 카드가 나오고, 첫날로 돌아간다.

- 한 판의 길이
  - 이기는 판: 약 70장(70일)
  - 처음에 죽는 판: 15~30장
- 1시간이면 8~12판을 한다.

## 3. 네 게이지

모두 0~100이고 50에서 시작한다. 카드 하나가 보통 게이지 1~3개를 ±5~20만큼 움직인다.

| 게이지 | 뜻 | 0이면 | 100이면 |
|---|---|---|---|
| **병사** | 부하들의 마음 | 밤에 등 뒤에서 찔린다 | 병사들이 나를 앞세워 들고일어난다. 주동자로 참수된다 |
| **조조** | 윗선의 신임 | 쓸모없다며 강등된다. 선봉에서 죽는다 | 너무 믿어서 가장 위험한 임무를 맡긴다. 돌아오지 못한다 |
| **군량** | 내 부대의 먹을 것 | 굶주린 병사들의 폭동 | 쌓아 둔 걸 들켜 횡령으로 처형 |
| **의심** | 곽가의 눈 (미래를 아는 티) | 아무도 내 말을 믿지 않는다. 진영이 무너지는 걸 보며 죽는다 | 원소의 첩자로 몰려 처형 |

- **미리 보기**: 카드를 반쯤 밀면 움직일 게이지 위에 점이 뜬다. 작은 점은 조금, 큰 점은 많이 움직인다. 오를지 내릴지는 보여 주지 않는다.
- **의심 게이지의 뜻**: 회귀자는 미래를 안다. 그걸 써먹을수록 의심이 오른다. 아예 안 쓰면 의심이 0으로 떨어진다. 아무도 내 말에 귀 기울이지 않는다는 뜻이다.

## 4. 카드 종류

| 종류 | 설명 | 분량 |
|---|---|---|
| 일반 | 덱에서 무작위로 나온다. 진영의 일상(배식, 보초, 다툼, 부탁) | 80~100장 |
| 줄기 | 선택에 따라 다음 카드가 열리는 짧은 이야기. 3~6장짜리 줄기 10개 정도 | 40~50장 |
| 이정표 | 정해진 날짜에 반드시 나온다. 관도의 큰 사건 | 8~10장 |
| 기억 | 회귀해서 얻은 기억이 있을 때만 나온다 | 15~20장 |
| 죽음 | 게이지 끝 8가지 + 사건 죽음 | 15~20장 |

**합계 160~200장.** 카드 한 장이 글 두세 줄이라 전체 글자 수는 2~3만 자다.

### 줄기 예시 (예전 이야기에서 가져옴)

- **여포의 목줄**
  - 여포가 군사를 달라고 한다.
  - 들어주면 병사 게이지가 오르고 조조 게이지가 내려간다.
  - 다음 판들에서 여포가 "듣는 건 공짜라 했지"라며 다시 온다.
- **전위와 호거아**: 미래를 아는 나만 위험을 안다. 알리면 의심이 오른다.
- **목책 밑의 굴**: 밤에 땅 울리는 소리를 듣는다. 진기를 믿을 것인가.
- **두석**: 다친 병사를 데려가면 군량이 줄고 병사 게이지가 오른다.
- **허유의 투항**: 그를 믿으라고 조조를 설득할 것인가.

## 5. 회귀와 기억 (판을 넘어 이어지는 것)

- **죽음 도감**: 한 번 겪은 죽음은 도감에 남는다. 처음 보는 죽음이 다음 판으로 갈 동기가 된다.
- **기억 카드**
  - 특정한 죽음이나 사건을 겪으면 기억이 하나 생긴다.
  - 예: "토산에서 벽력거에 깔려 죽었다"
  - 다음 판에서는 관련 카드에 "전에 이걸 겪었다"는 표시가 붙는다.
  - 새 카드가 열리기도 한다. 예: "유엽에게 벽력거 그림을 그려 준다"
- **회귀 횟수**: 화면 구석에 "n번째 관도"로 보인다. 인물들의 대사가 회귀 횟수에 따라 조금씩 달라진다. 예: 곽가 "자네, 처음 보는 얼굴이 아닌 것 같군."
- **목표 사다리**
  1. 백마까지 살아남기
  2. 토산 넘기기
  3. 허유 맞이하기
  4. 오소의 밤

  한 번 닿은 이정표는 기록된다.

## 6. 이정표 (날짜 고정)

| 날 | 사건 | 그날의 시험 |
|---|---|---|
| 5 | 백마 — 안량 | 조조 게이지가 낮으면 선봉에 배치된다 |
| 12 | 연진 — 문추 | 군량 미끼를 쓸 것인가 |
| 20 | 토산과 화살비 | 병사 게이지가 낮으면 방패가 모자란다 |
| 28 | 벽력거 | 기억이 있으면 미리 알릴 수 있다 (의심 상승) |
| 38 | 목책 밑의 굴 | 진기 줄기를 따랐으면 막아 낸다 |
| 48 | 군량이 바닥난다 | 군량 게이지의 시험 |
| 60 | 허유의 투항 | 조조·의심 게이지가 결과를 가른다 |
| 70 | 오소의 밤 | 결말 |

## 7. 결말 (3~4개)

- **오소의 불**: 살아남아 오소를 태운다. 기본 결말.
- **이름 없는 공**: 공은 남이 가져갔지만 내 병사들이 다 살았다. 병사 게이지가 높은 채로 도달하면 나온다.
- **곽가의 술잔**: 곽가가 나를 알아본다. 의심이 높은 채로 도달하고, 기억을 여럿 가졌을 때 나온다.
- **진결말 (숨김)**: 모든 기억을 모으고 오소에 닿으면 나온다. 회귀의 이유가 밝혀진다.

## 8. 등장 인물 (그림이 이미 있는 35명)

| 쪽 | 인물 |
|---|---|
| 조조 쪽 | 조조, 곽가, 순유, 유엽, 만총, 장료, 조홍, 조앙, 전위, 전만 |
| 원소 쪽 | 원소, 저수, 심배, 곽도, 허유, 순우경, 장합, 고람 |
| 객장과 그 주변 | 여포, 진궁, 관우, 유비, 가후, 호거아 |
| 내 부대·병사들 | 두석, 왕삼, 조노, 소칠, 진기, 이석, 장오, 백부장, 모팔, 위림, 마오 |

예전 대사와 성격을 그대로 쓴다. 장면이 아니라 두세 줄로 줄인다.

## 9. 화면

- 위: 게이지 아이콘 넷 (병사·조조·군량·의심), 날짜, 회귀 횟수
- 가운데: 인물 그림 카드. 밀면 기울고, 좌/우 선택 문구가 뜬다.
- 아래: 카드를 든 사람 이름
- PC는 ←/→ 키와 마우스 끌기, 휴대폰은 스와이프
- 예전 배경 그림 100장과 음악 16곡, 효과음은 이정표와 죽음 카드에 그대로 쓴다.

## 10. 카드 데이터 형식

```json
{
  "id": "lvbu_troops_1",
  "who": "lvbu",
  "text": "군사를 나눠라. 내가 앞장선다.",
  "left":  { "label": "거절한다", "fx": { "soldier": -5, "cao": +10 } },
  "right": { "label": "나눠 준다", "fx": { "soldier": +10, "cao": -15 }, "set": ["lvbuTroops"] },
  "need": ["day>=3", "!lvbuTroops"],
  "weight": 2
}
```

- `need`: 조건 (날짜, 표시, 기억, 회귀 횟수)
- `set`: 이번 판의 표시
- `mem`: 판을 넘어 남는 기억
- 줄기 카드는 `need`로 앞 카드의 표시를 건다.
- 검수 단위가 카드 한 장(글 두세 줄)이라 지금처럼 수정이 수정을 부르는 일이 없다.

## 11. 만드는 순서

1. **맛보기판**: 카드 30장, 이정표 2개(백마·토산), 죽음 8개, 회귀 반복
   - 직접 몇 판 해 보고 재미를 확인한다.
   - 게이지 수치를 맞춘다. 너무 쉽거나 너무 빨리 죽지 않게.
2. **줄기 10개와 이정표 전부**
3. **기억과 결말**
4. **나머지 일반 카드를 채운다.** 한 판 평균 길이를 시험 플레이로 맞춘다.

## 12. 정할 것

- 게임 이름 (가제 "관도 회귀")
- 주인공을 말단 군관으로 할 것인가 (권함). 조조 본인이나 참모로 할 수도 있다.
- 예전 『관도지로』는 브랜치에 그대로 두고, 새 게임은 새 파일(`reigns.html`)로 만든다.
