# 대본 — 12장 심문 「자네는 누군가」 세 갈래 (설계 3번)

> 설계 문서 4절을 실제 대사로 옮겼다. **아직 반영 전이다.**
> 표기: 이름 없는 줄은 서술이다. `[조건]`은 그 줄이 나오는 판이다. **(기존)**은 지금 대본에 있는 줄을 그대로 쓴다는 뜻이다.

---

## 0. 구조

지금 심문은 하나다. 조조가 기록을 꺼내고, 조노·저수(B는 여포)가 증언하고, 「죽었다 깨어났다 / 주공의 군사 / 끝을 읽었다」 가운데 하나를 고른다.

바꾼 뒤에는 이렇다.

| 순서 | 내용 | 갈래 |
|---|---|---|
| 1 | 등잔, 만총의 편지, 흉, 가장 무거운 기록 하나, "자네는 누군가" | 셋 다 같다 **(기존)** |
| 2 | 만총의 결론을 조조가 읽는다 | **결론마다 다르다 (새 줄)** |
| 3 | 조노 증언 ("진류의 조가 아니냐") | 셋 다 같다 **(기존)**. 조조의 물음만 결론에 맞게 바꾼다 |
| 4 | 저수 증언(A) / 여포(B) | 저수는 간자 갈래에만 나온다. 여포는 셋 다 나온다 |
| 5 | 마지막 선택 셋과 결말 | **결론마다 다르다 (새 줄)** |

의심이 낮아 심문까지 가지 않는 판(「평범」)은 지금의 가벼운 장면(조공이 술 오른 얼굴로 "자네는 누군가" 묻는 장면) 그대로다.

### 결말 표

| 결론 | 선택 | 결말 | 지금 결말 이름 |
|---|---|---|---|
| 간자 | 보낸 것이 없다 | 감시 서리가 붙는다. 조노가 감싼 판이면 조조가 편지를 태운다 | watched / hero |
| 간자 | 말할 수 없다 | 추방. 조노가 감싼 판이면 감시로 그친다 | exiled / watched |
| 간자 | 끝을 읽었다 | 감시. 간자 의심은 풀린다 | watched |
| 은사 | 스승은 죽었다 | 조조가 실망한다. 공은 그대로, 부대로 돌아간다 | **unit (새)** |
| 은사 | 혼자 익혔다 | 유엽 밑에서 허도 공방을 맡는다 | **workshop (새)** |
| 은사 | 데려올 수 없는 곳에 있다 | 만총에게 넘겨진다. 감시 | watched |
| 방사 | 압니다 | 지금의 「끝을 읽었다」 결말. 조노가 정직하게 증언한 판은 추방, 아니면 감시 | exiled / watched |
| 방사 | 모릅니다 | 감시 | watched |
| 방사 | 제가 읽은 대로 되지 않을 겁니다 | 조조 곁. 출전도 귀향도 없이 조조가 밤마다 부른다 | **side (새)** |

## 1. 공통 첫머리 (기존)

```
군관들이 물러간 뒤에도 조공은 나를 내보내지 않았다. 순유와 가후도 나갔다. 군막에는 조공과 나, 그리고 등잔 하나가 남았다.
탁자 위에 편지가 한 통 펼쳐져 있었다. 봉인에 허도 현령의 인장이 찍혀 있었다.
[간자 · 새 줄] 편지 옆에 칼이 한 자루 놓여 있었다. 칼집에서 반쯤 빠져 있었다.
조조: 연주 동군, 강가 마을. 자네 어미가 일러 준 왼손의 흉이 자네 손에 있다더군. 몸은 그 집 아들이 맞는 셈이지.
조조: 그런데 그 아들은 제 이름자도 못 썼다더군.
(가장 무거운 기록 한 줄 — 기존)
조조: 몸은 조평인데, 하는 일은 조평이 아니야. 자네는 누군가.
나는 입을 열었다가 닫았다. 무엇부터 말해야 할지 몰랐다.
```

## 2. 조조가 만총의 결론을 읽는다 (새 줄)

지금 "조공은 재촉하지 않았다. 대신 군막 밖을 향해 사람을 불렀다." 앞에 들어간다.

### 간자
```
조조: 만총은 자네 뒤에 누가 있는지부터 찾으라고 썼네.
조조: 원소 진영의 일을 우리보다 먼저 알았다지. 그런 걸 알려 줄 사람은 원소 진영에 있겠지.
조조: 그래서 묻겠네. 원소에게는 무엇을 보냈나.
```

### 은사의 제자
```
조조: 만총은 자네를 가르친 사람을 찾으라고 썼네. 자네가 이만큼 안다면 그 사람은 더 알 거라더군.
조조: 나도 같은 생각이네. 그 사람이 누군지 말하게. 데려오면 자네보다 높은 자리에 앉히겠네.
```

### 방사
```
조공은 편지 끝을 손가락으로 짚었다.
조조: 만총은 자네가 일이 벌어지기 전에 안다고 썼네. 어떻게 아는지는 자기도 모르겠다더군.
조조: 만총이 이런 말을 쓰는 사람이 아니네. 귀신 이야기를 하면 그 자리에서 내쫓는 사람이야.
조조: 그런 사람이 지우지 않고 보냈으니, 나도 그냥 넘길 수가 없네.
```

이어서 기존 줄 "조공은 재촉하지 않았다. 대신 군막 밖을 향해 사람을 불렀다."

## 3. 조노 증언 (기존, 물음만 바꾼다)

"…너. 진류의 조가 아니냐. 내 첫 깃발을 들던." ~ "그 뒤로는 무슨 자리를 줘도 마다했지."까지는 그대로 둔다.

그다음 조조의 물음이 결론마다 다르다. 조노의 대답 두 가지(감싸는 거짓말 / 정직한 대답)는 그대로다.

| 결론 | 조조의 물음 |
|---|---|
| 간자 | 복양 도랑에서 이자를 처음 봤을 때, 이자는 누구였느냐. **(기존)** |
| 은사 | 이자에게 글을 가르친 자가 누구냐. 너라면 알 것 아니냐. |
| 방사 | 복양 도랑에서 이자를 처음 봤을 때, 이자는 누구였느냐. **(기존)** |

은사 갈래에서 조노가 감싸는 판:
```
조노: …글은 도랑에서 제가 가르쳤습니다. (기존 대사와 같다)
조공이 조노를 봤다. 조노가 글을 모른다는 것은 명부를 한 번이라도 올려본 사람이면 다 알았다. (기존)
[은사 · 새 줄] 조조: 네가 가르쳤다고. 네 이름자도 남이 써 주는 놈이.
[은사 · 새 줄] 조노는 대답하지 않았다. 조공도 더 묻지 않았다.
```
조조는 거짓말인 걸 안다. 그래도 조노가 거짓말까지 하며 감싼다는 사실이 조조에게는 증언이 된다. 결말 계산은 지금처럼 `jonoWitness=protect`로 남긴다.

## 4. 저수(A) · 여포(B)

- **저수 증언**(기존: "원소의 사람이었다면, 내가 이 이름을 찾아다닐 이유가 없었겠지요. … 간첩은 이렇게 일하지 않소.")은 **간자 갈래에만** 나온다. 은사·방사 갈래에서는 저수를 부를 까닭이 없다.
- **여포**(기존: "밖에서 다 들리더군. 간첩이든 뭐든, 이자 덕에 내 목이 아직 붙어 있소.")는 셋 다 나온다. 간자 갈래에서 8장 편지를 조평이 직접 바친 판이면 한 줄을 더한다.
```
[B · 간자 · 8장에서 장오가 원소의 편지를 들고 돌아온 판]
여포: 원소가 나한테 보낸 편지 말이오. 그걸 조공께 들고 간 게 이자요. 간자가 제 주인 편지를 남의 주인에게 갖다 바치오?
```

## 5. 마지막 선택과 결말

### 5-1. 간자

```
조조: 다시 묻겠네. 원소에게는 무엇을 보냈나.
```
| 선택지 | 부제 |
|---|---|
| 「"보낸 것은 없습니다."」 | 아는 것은 다 이 군막 안에서 말했다. |
| 「"말씀드릴 수 없는 것이 있습니다."」 | 다 말하지는 않는다. |
| 「"이 싸움의 끝을 읽었습니다."」 | 있는 그대로 말한다. |

**보낸 것은 없습니다**
```
나: 보낸 것은 없습니다. 제가 안 것은 다 주공의 장수들 앞에서 말했습니다.
나: 원소에게 보낼 생각이었다면, 먼저 주공 쪽에 알릴 까닭이 없습니다.
조공은 칼을 보지 않고 나를 봤다.
[조노가 감싼 판] → 기존 결말: 조조가 편지를 등잔 위로 가져간다. "어디서 왔든 상관없다. 쓸모가 있는 동안은." (hero)
[그 밖의 판] 조조: …좋네. 벼슬은 그대로 두지. (기존) → 감시 서리 (watched)
```

**말씀드릴 수 없는 것이 있습니다**
```
나: 말씀드릴 수 없는 것이 있습니다. 다만 원소와는 상관이 없습니다.
조조: 간자라는 말을 듣고도 할 수 없는 말이 있다는군.
[조노가 감싼 판] 조조: 진류의 조가가 거짓말까지 하며 감싼 자다. 목은 붙여 두지.
[조노가 감싼 판] → 감시 서리 (watched)
[그 밖의 판] 조조: 무엇을 숨기는지 모르는데 자네를 곁에 둘 수는 없네. …데려가라.
[그 밖의 판] → 기존 추방 장면 (exiled)
```

**이 싸움의 끝을 읽었습니다**
```
나: …믿지 않으실 겁니다. 저는 이 싸움의 끝을 읽은 사람입니다. (기존)
등잔 불이 한 번 흔들렸다. 조공은 웃지 않았다. (기존)
조조: 간자라면 그런 말은 하지 않지. 붙잡혀서 그런 말을 하면 목이 먼저 떨어지니.
조조: 원소에게 무엇을 보냈는지는 이제 묻지 않겠네. 대신 다른 걸 물어야겠군.
조공은 편지를 접어 소매에 넣었다. 태우지 않았다. (기존)
→ 감시 서리 (watched)
```

### 5-2. 은사의 제자

```
[조노가 감싼 판] 조조: 조가는 자기가 가르쳤다는군. 그건 거짓말이고. 그럼 진짜 스승은 어디 있나.
[그 밖의 판] 조조: 그래서, 그 스승은 어디 있나.
```
| 선택지 | 부제 |
|---|---|
| 「"스승은 죽었습니다."」 | 데려올 수 없다고 말한다. |
| 「"스승은 없습니다. 혼자 익혔습니다."」 | 거짓은 아니다. |
| 「"데려올 수 없는 곳에 있습니다."」 | 더 말하지 않는다. |

**스승은 죽었습니다**
```
나: 스승은 죽었습니다. 제가 도랑에 빠지기 전 일입니다.
조조: 죽었다. …편한 대답이군. 죽은 사람은 아무도 데려올 수 없으니.
조조: 그 사람이 무엇을 더 알았을지는 이제 아무도 모르겠군.
조공은 편지를 접었다. 아까보다 목소리가 낮았다.
조조: 벼슬은 그대로 두지. 부대로 돌아가게.
→ 부대로 (unit)
```

**스승은 없습니다. 혼자 익혔습니다**
```
나: 스승은 없습니다. 쇠고리도, 측량도, 숫자도 혼자 익혔습니다.
조조: 혼자 익혔다. 그럼 내가 찾던 스승이 자네로군.
조조: 유엽이 허도에 공방을 차린다네. 거기서 자네가 아는 걸 장인들에게 가르치게. 자네 혼자 알고 있다가 자네가 죽으면 그걸로 끝이네.
조조: 만총에게는 내가 쓰지. 스승은 찾았다고.
→ 허도 공방 (workshop)
```

**데려올 수 없는 곳에 있습니다**
```
나: 데려올 수 없는 곳에 있습니다. 더는 말씀드릴 수 없습니다.
조조: 저승인가, 원소 진영인가. 아니면 내가 모르는 곳인가.
조공은 대답을 기다렸다. 나는 대답하지 않았다.
조조: 그 말은 허도에 가서 만총에게 다시 하게. 그 사람은 나보다 끈질기네.
→ 감시 서리 (watched)
```

### 5-3. 방사

```
조조: 그럼 묻겠네. 내 끝도 아는가.
```
| 선택지 | 부제 |
|---|---|
| 「"압니다."」 | 있는 그대로 말한다. |
| 「"모릅니다."」 | 거짓말이다. |
| 「"주공의 끝은 제가 읽은 대로 되지 않을 겁니다."」 | 이미 많이 바뀌었다. |

**압니다**
```
나: …압니다. 저는 이 싸움의 끝을 읽은 사람입니다. 주공의 끝도 거기 있었습니다.
조조: 말하지 말게.
조공이 손을 들어 내 말을 막았다.
조조: 듣고 나면 그날을 세며 살게 될 테니.
[조노가 정직하게 증언한 판] 조조: 증언은 들었네. 그러나 끝을 안다는 자를 곁에 두는 건, 내 목을 그자에게 맡기는 일이야. …데려가라. (기존) → 추방 (exiled)
[그 밖의 판] 조조: 끝을 읽은 자라면, 더더욱 곁에 두어야겠지. (기존) → 감시 서리 (watched)
```

**모릅니다**
```
나: 모릅니다.
조조: 하비에서는 원소의 기병을 알았는데, 내 일은 모른다.
조공은 한참 나를 봤다. 거짓말인 걸 아는 얼굴이었다. 그래도 더 캐지는 않았다.
조조: 모른다고 해 두지. 그 편이 서로 편하겠군.
→ 감시 서리 (watched)
```

**주공의 끝은 제가 읽은 대로 되지 않을 겁니다**
```
나: 주공의 끝은 제가 읽은 대로 되지 않을 겁니다. 벌써 많이 달라졌습니다.
[조앙 생존] 나: 제가 읽은 대로라면 공자께서는 완성에서 돌아오시지 못했습니다.
[여포 생존] 나: 제가 읽은 대로라면 온후께서는 하비에서 목이 떨어지셨습니다.
[둘 다 아닐 때] 나: 제가 읽은 대로라면 저는 복양 도랑에서 죽었습니다.
조공이 웃었다. 군막에 든 뒤로 처음이었다.
조조: 그럼 자네가 읽은 끝은 자네 손으로 바꿀 수 있는 끝이군.
조조: 출전은 보내지 않겠네. 고향에도 보내지 않겠네. 밤에 부르거든 오게.
→ 조조 곁 (side)
```

## 6. 사실 확인
- 조조 → 주인공: 하게체(자네). 조조 → 조노: 해라체(너). 조노 → 조조: 합니다체. 여포 → 조조: 하오체. 지금 대본과 같다.
- 유엽이 관도에서 발석거를 만든 것은 『삼국지』 유엽전에 있다. 허도 공방은 이 게임에서 만든 자리다.
- 만총이 귀신 이야기를 물리친 것은 11장 막간의 대사("귀신이 씌었다는 말은 무당들이나 하는 소리다")와 이어진다.
- 「제가 읽은 대로라면」 줄은 그 판에서 실제로 바뀐 일만 말한다. 조앙은 사서에서 완성에서 죽었고(197년), 여포는 하비에서 처형됐다(198년) — 『삼국지』 무제기·여포전.
